# 2026-10-25 — 개인 사례 종속을 끝내고 공개 다중 사례 평가로 전환

## 결정 이유

사용자는 특정 반려견 전용 모델이 아닌 보편적인 reference-guided video object editing을 단일 DGX Spark에서 연구하려는 목표를 다시 명확히 했다. 앞서 특정 IG의 기립 사진을 요구한 것은 B-026의 선택적 참조 자세 비교에 필요한 조건일 뿐 전체 연구의 선행조건이 아니다. 이 좁은 진단으로 인해 연구 전체가 대기하는 운영을 수정한다.

확인한 기준 HEAD는 `84e00dc28691c64cc84ed667b29b2de31f6d688f`. B-026은 REFERENCE_PENDING/GPU0으로 보존하고, 개인 사진 추가는 요청하지 않는다. B-024/B-025는 회귀·실패 사례로 보존하며 새 공용 평가의 성공이나 실패로 소급 수정하지 않는다.

## 새 주력 다음 작업

[B-027 계획](../experiments/B-027-public-reference-robustness/PLAN.md): 공개 source/target 자료에서 최대3개의 서로 다른 편집 task를 선택하고, 같은 target track의 다른 자세·시점 참조2장을 비교한다. 최대6개 실제 생성 결과를 얻는다. 모델은 이미 실행되는 정식 SCAIL replacement와 RGB 배경128 처리를 고정한다. 학습0·새모델다운로드0, 공개자료 다운로드는 명시적으로 최대5GiB 허용하는 실행 제안이다.

공개 자료를 실제 확보·선정하는 책임은 실행 담당자에게 있으며 사용자가 새로운 개인 사진을 제공하는 것이 조건이 아니다. 여러 공개 후보 중 하나가 막혀도 적합한 다른 후보나 준비된 pair로 진행하고, 모든 자료의 실제 접근/사용조건이 막힌 경우만 구체적으로 보고한다. 자료의 이용 범위는 준수하며 새계정·신청·유료/외부 생성으로 우회하지 않는다.

이는 성능이 검증된 새 편집 방법이나 논문용 최종 benchmark가 아니다. 현재 기준선이 어느 객체·참조 조건에서 외형과 동작을 분리해 활용하는지 확인할 작은 개발 패널이다. 동물·사람/인간형·강체의 범위를 구분하고, SCAIL의 특정 도메인 실패를 일반적 영상 편집의 불가능으로 결론내리지 않는다.

## 앞으로의 판정 기준

모델을 다시 설치하거나 학습배선이 작동하는지만 검사하는 단계로 돌아가지 않는다. 데이터/안전/실행정합은 확인하되, 산출물의 중심은 실제편집영상·고정평가표·실패분류·전체비용이다. sourcecopy와reference정지복사를성공에서구분한다.

편집정답영상이없어도추론평가는가능하다. 다만source의객체영역을pixelGT로쓰거나pairedsupervision이확보됐다고가정하지않는다. 추후학습은방법에맞는target·loss·split을별도로설계한다.

결과이후한가지구체적방법개입을선택한다. 참조자세누수가반복되면외형/공간배치조건의분리, 참조를무시하면identity주입, 보호장면만실패하면문맥/합성, 특정객체군실패면backend적합성을우선검토한다. 개인의더쉬운사진확보나무한update/sweep를대안으로삼지않는다.

## 관련문헌의 위치

DAVIS공식페이지에서공개프레임·마스크를확인했고사이트의dataset metadata는CC BY-NC4.0을표기한다. VPBench공식카드와VideoPainterREADME도확인했다. 데이터개방과상용사용/재배포허가를혼동하지않는다.

VideoSwap의semantic correspondence, VideoAnydoor의identity/trajectory/pixel warper, VideoPainter의context/inpainting은가까운기존접근이다. 이번에는논문/코드공개현황을검토할뿐모두설치·비교완료했다고하지않는다. VideoAnydoor의공식README는검토당시코드release준비상태를명시했다.

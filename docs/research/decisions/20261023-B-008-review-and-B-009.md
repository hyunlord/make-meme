## 추가 발견

reference mask BLACK344,824/RED113,928 pixels, WHITE0을 직접 계수했다. 조건 safetensors의 양 CFG branch ref_masks [28,6,112,64]도 white channel 전체0, reference plane red 평균0.24834333147321427로 확인했다. 이는 실제 모델 조건에 반영된 차이다.

현재는 animation(`replace_flag=False`)이며, 성공한 인간 animation_001의 기존 감사는 reference WHITE background / driving BLACK background였다. 고정 공식 문서상 색 mask는 alpha가 아니라 background visibility와 character correspondence를 함께 지시한다. BLACK이 모든 reference 사용에서 잘못이라는 뜻은 아니지만, RED ID가 같다는 확인만으로 충분한 입력 동등성을 입증한 것은 아니다.

참조 RGB는 VAE/CLIP 경로에 별도로 들어간다. mask가 BLACK인 영역이 곧 참조 이미지에서 수학적으로 삭제되는 것은 아니다. 또한 원본 배경 보존이 목표인 character replacement와 reference character animation을 구분한다. 참조 침실이 보이는 사실 하나만으로 두 과제를 섞어 품질 판정하지 않는다. 직립 동작 실패는 명확하다.

## 정정과 연구 결정

이전 계획이 RED correspondence에 비해 reference background visibility 차이를 충분히 분리하지 않은 점을 보완한다. 모델 능력·체형 전이 한계를 결론내리기 전에, **Lab RGB·모션·text·seed를 유지하고 reference mask BLACK background만 WHITE로 바꾸는1회 통제 비교**를 우선한다.

이것은 mask가 유일한 원인이라는 선언이 아니라 다음에 검증할 가설이다. 공식 예제와 맞춘 semantic input 비교이며, VACE의 회색 reference/검은 Canny 실험을 무한 반복하는 방향으로 확대하지 않는다.

source 첫 프레임 자기 재현은 이후 후보로 보존한다. 다만 그 참조 자체가 이미 직립이라 정지 복사도 upright를 통과하므로, 향후 진단에는 비생성 first-frame-repeat 대조군과 실제 시간 변화 판정이 필요하다. 한seed/짧은 구간의 통과가 개체 전이·학습 일반화의 증거는 아니다.

추가 정정: 공식 README는 mixed resolutions and fps 학습을 명시한다. writer의16fps 기본값을 모델이16fps로만 학습됐다는 근거로 쓰지 않는다. 현재24fps를 실패 원인으로 확정하지 않는다.

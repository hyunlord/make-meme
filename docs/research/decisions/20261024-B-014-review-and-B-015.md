## 읽은 근거와 한계

기준 원격 commit `14afab19df2d9b464b3d6685e24747a675ac9660`에서 B-014 RESULTS, ADAPTATION_AUDIT, code/alg.py, code/alg_runtime.py를 조회했다. ALG 원논문 HTML v2(https://arxiv.org/html/2506.08456v2)의 Eq.(2)도 확인했다. 이번 검토는 코드/기록 대조이며 Spark 재실행이 아니다.

## 확인한 것

- 코드: 활성 i0..7의 u_orig+5*(c_low-u_low), 비활성 기존 CFG, spatial-only 필터와 비수정 원본 cache, 순차3branch. runtime의 filtered sidecar는 parent reference 및 parent cache SHA를 강제한다.
- 기록: 40step/88forward, S guard1266.471초, sampler1116.131초, final latent/17f24fpsMP4 보존. 전신FAIL·후반 얼굴/귀 손상 지속·실제개체UNCERTAIN·temporalUNVERIFIED. 목표품질 개선 NOT_ESTABLISHED.
- 현재 이식은 참조조건 전체의 완화가 아니다. 원래reference를 사용하는 negative 기준항, CLIP·semantic mask·큰 저주파 구조가 남는다. 이를 'reference는 원인이 아니다' 또는 'ALG 전체가 무효'로 확대하지 않는다.
- 동일 z에서 CFG와 ALG 차이는 w[(c_low-u_low)-(c_orig-u_orig)]다. 실제 생성궤적은 달라지고 runtime에는 branch norm만 있으므로, 작은/큰norm 차이로 조건경쟁·상쇄의 크기를 측정했다고 말하지 않는다.
- 공식I2V의 움직임 양 개선과 우리 cross-identity의 정확한 자세/동작/개체 동시 유지라는 목적을 구분한다. 지금은 구현재현·이식의 학습성과이지 품질성공/새논문방법이 아니다.

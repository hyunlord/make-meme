# 종료 이미지 하나와 시간 전체의 조건 충돌

## 직관과 수식

원본의 마지막 낮은 머리 상태와 target의 체형은 같지 않다. 같은 행동 단계라도 털 길이·다리 비율·머리 크기가 달라 silhouette은 달라진다. source를 따르라는 요구와 너무 낮은 종료 앵커를 따르라는 요구가 충돌하면 조건을 늘리는 것만으로 두 요구를 동시에 만족시킬 수 없다. 이번에는 새로운 구조 모듈 대신 입력 단계로 돌아가 종료 앵커 한 장을 바꿨다.

V는 원본33장, A0는 고정 시작, A32는 기존 종료, A32'는 새 종료, L은 고정 동적 윤곽, P는 같은 텍스트, epsilon은 동일 초기 noise다.

`Y = H_theta(A0,A32,L,P;epsilon)`

`Y' = H_theta(A0,A32',L,P;epsilon)`

H_theta의 가중치와 샘플러는 바뀌지 않았다. 따라서 새 알고리즘의 효과가 아니라 교정 앵커 전체의 효과를 본다. A32'는 자세뿐 아니라 얼굴·털·빛·배경 질감도 달라져 자세 한 변수만의 순수 인과효과가 아니다.

## 실제 입력과 함수

C002 `video_generate.condition`은 같은 firstlastframe helper의 X0/X32와 G를 만들고 중간31장을 기존 L로 교체한다. C004는 이 함수를 수정하지 않고 end_anchor/output 설정만 바꿨다. 실제 pixel hash로 X0..31 동일, X32만 변경을 확인했다.

X를 RGB×2/255−1로 정규화하면 `U=Encoder((1-G)*Normalize(X))`, `R=Encoder(G*Normalize(X))`다. G의 끝은0, 중간은1이므로 마지막 앵커 변경은 inactive의 끝 입력에 들어가고 reactive와 G는 동일하다. 정규화된0은 uint8의 검정0과 다르다. U16+R16+mask64가 context96채널로 결합된다.

33개 영상 표본 t는 VAE에서9개 시간 latent 위치가 되고,50 Euler step s는 noise를 점진적으로 영상으로 바꾸는 반복이다.50step은50프레임이 아니다. 기존 nearest-exact33→9 mask에서 끝0이 빠지는 한계는 그대로이며, RGB inactive 앵커가 남는 것과 구분한다.

시간 VAE와 영상 Transformer가 여러 시점을 결합하므로 마지막 RGB 한 장 변경이 마지막 latent 하나에만 국한된다는 assertion은 틀리다. 중간 출력도 달라질 수 있지만, 달라짐과 원본 진행 개선은 별도 증거를 요구한다. 실제 noise/context/mask 관측은 NUMERICS에 기록한다.

## 해석의 한계

새 앵커는 PARTIAL_BUT_USABLE이다. 주둥이가 약간 올라갔지만 몸통 상태는 유사하고 source도 이미 낮은 머리다. 강한 자세 충돌 교정이 성공했다고 전제할 수 없다. 머리 방향의 정면화와 세부 무늬·배경 변화도 함께 생겼다. 입력 조작이 약하면 영상 이득이 없을 때 그 원인을 앵커 충돌과 무관하다고 단정할 수 없다.

실제 출력의 종료부와 중간 진행을 나눈 관측은 RESULTS를 따른다. 관절·발 접촉 GT가 없고 정적 검토만으로 연속 품질을 확정하지 않는다. 이번 후 추가 앵커 튜닝·학습·새 모델은 없다. 남은 실패는 부위 ID·시간 대응·가시성·신뢰도를 생성기에 전달하는 방법을 논의할 근거로만 사용한다.

## 실제 관측과 반례

새 영상에서는8/16의 얼굴 방향과32의 주둥이 높이가 달라졌지만, 같은 인덱스의 머리·앞발 진행이 기준보다 명확하게 좋아지지는 않았다.29–31의 낮은 머리·뻗은 앞발 전환이 남고 오른쪽 전경에 줄기 같은 형태가 더 두드러졌다. 따라서 입력은 전달됐지만 NO_ESTABLISHED_GAIN이다. 마지막 RGB 하나가 중간에도 영향을 준다는 사실은 관측됐으나, 그 영향이 원하는 동작 정보라는 보장은 없다.

전체화면 endpoint L1은18.6564에서16.9864로 작아졌지만 비교 앵커가 다르다. 작은 오차만으로 머리·발 진행 성공을 주장할 수 없다는 실제 반례다. 약한 앵커 교정 때문에 입력 충돌의 기여를 완전히 배제하지도 못한다.

## 이해 확인

1. 끝 이미지 한 장만 바꾸면 중간은 같아야 하나? 아니다. 논리 입력의 변경 위치와 시간 모델의 영향 범위는 다르다.
2. 새 앵커의 pixel 오차 감소가 동작 성공인가? 아니다. 더 쉬운 앵커나 외형 변경도 오차를 줄일 수 있다.
3. 원본 자세를 지키려면 target 실루엣을 원본에 완전히 맞춰야 하나? 아니다. 보이는 부위 관계와 행동 상태를 우선하고 자연스러운 체형 차이를 허용한다.
4. 결과가 좋아지면 새 알고리즘인가? 아니다. 같은 모델의 입력 충돌 진단이며 한 사례·한 seed다.

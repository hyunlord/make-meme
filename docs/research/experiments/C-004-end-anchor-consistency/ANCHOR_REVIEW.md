# 영상 전 앵커 판정 — PARTIAL_BUT_USABLE

실제 native1call/1candidate를 확인했다. source32/target crop/raw시작/oldend/newend를 실행자와 같은 세션의 별도 에이전트가 정적으로 검토했다(독립 human 평가 아님). 새 얼굴·주둥이가 기존 end보다 약간 올라가고 더 정면으로 보이며, 큰 체형·배치·검정/흰 디자인 손상은 없어 한 번의 영상 비교에 사용한다.

이것은 큰 웅크림 문제가 해결됐다는 판정이 아니다. 몸통·앞발 관계는 대체로 비슷하며 source도 이미 낮은 머리다. 새 코가 source의 방향과 다르게 더 정면을 향하고 가까운 발도 화면상 조금 높아졌다. 미세 흰 무늬·털과 배경 질감도 바뀌므로 자세만의 개입이 아니다. 주요 충돌 감소는 얼굴/주둥이의 부분적 방향 변화로 한정하고 이 약한 조작이 영상 해석을 제한함을 사전 기록한다.

| 사전 기준 | 영상 전 판단 |
|---|---|
| source의 머리/몸통 관계 | 얼굴 낮아짐 일부 완화; 몸통은 유사, 완전 일치 아님 |
| 보이는 앞발 배열/겹침 | 화면 왼쪽 전방·오른쪽 후방 관계 대체로 유지; 접촉은 UNCERTAIN |
| target/start 외형 | 검정 긴 털·흰 이마/주둥이/가슴/발 유지; 세부 동일성 PARTIAL |
| 단일 대상/형태 | 큰 중복·붕괴 없음; 가려진 관절 정답은 판단하지 않음 |
| 카메라/장면 | 큰 구조·배치 유지, 잔디 질감/조명 세부 변경 |

원출력1652×952를 보존하고 C001과 동일 aspect-fit LANCZOS832×479,832×480 검정 canvas(offset0,0)만 적용했다. warp/crop/발이동/배경합성0. 원본해시와 모델해시는 ANCHOR.json에 기록했다. 이번 출력 한 장을 그대로 사용하며 재생성/선별0이다.

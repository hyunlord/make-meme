# 생성 전 source 이벤트 계약

source만 보고 다음 local 시점을 고정한다. 이후 출력에 맞춰 시점·구간·점을 바꾸지 않는다. 전체17장도 빠짐없이 검토한다.

| local / 원본 | 실제 가시적 사건 |
|---|---|
| 0 / 7 | 정면 몸통, 앞발은 주둥이보다 아래. 머리는 약하게 기울어져 있고 양눈 선은 비교적 완만하다. |
| 12 / 19 | 앞발은 계속 주둥이 아래이며 몸통은 정면 기울임을 유지. 머리 roll은 아직 뒤의 endpoint보다 작다. |
| 14 / 21 | 머리 roll이 뚜렷하게 시작/증가한다. 머리 방향 변화가 몸통의 정면 기울임보다 크며 앞발은 몸 앞에 남는다. |
| 16 / 23 | 양눈 선이 가파르게 기울어진 큰 머리 roll. 몸통 전체가 같은 각도로 옆으로 돌아간 것은 아니며 양 뒷발과 정면 배가 보인다. |

MOV/STILL/STATIC COPY가 이 방향·순서·발생 시점과 머리-몸통 상대 배치를 얼마나 유지하는지 비교한다. 앞발의 정확한 끝점/작은 상대 변화는 UNCERTAIN이고 숨은 관절·접지하중·3D 회전각은 UNKNOWN이다. 정량 위치 오차는 NOT_CALIBRATED다. 점을 추가해 유리한 것만 고르거나 자동 정렬/zoom/시간 지연 최적화하지 않는다. 초기 평범한 직립 유지와 낮은 flicker만으로 성공하지 않는다.

MOV가 STILL 및 STATIC COPY보다 이 사건에 명확히 가까울 때만 이 한 입력에서 동적인 RGB+mask pair가 추가 제어 정보를 주었다는 탐색적 근거로 해석한다. 크기만 다른 움직임은 성공이 아니다. STILL은 정적인 driving을 받는 생성 대조군이며 움직여도 곧 실패가 아니다. 정적인 mask도 같이 반복하므로 이번 개입은 RGB만의 효과가 아니다.

가능하면 출력 패널 A/B 별칭으로 비교하되 source를 본 같은 에이전트이므로 완전 blind/독립 인간 평가라고 주장하지 않는다. 17프레임을17독립 반복으로 세지 않는다. 오차보정 없는 gain/통계적 유의성은 계산하지 않는다. 실제 연속 재생을 관찰하지 못하면 temporal UNVERIFIED, Lab/IG 전이·일반화는 NOT_RUN이다.

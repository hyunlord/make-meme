# Source-only 선정

원본 manifest가 가리키는 기존 승인 영상만 확인했다. 원본 SHA256 `da33bb95d4e05c49c537f3fdb27b2189fafec2b4f8d1a27e6b14efe034071f6b`, 실제 1916×1078, 24fps, 디코딩 361프레임이다. 파일명의 15초를 정확한 frame count로 대신하지 않는다. 생성 결과 없이 12프레임 간격 소형 timeline을 보고 아래 세 후보를 먼저 고정한 뒤 각17장을 직접 보았다.

| 후보 (원본 index, stop exclusive) | 판단 |
|---|---|
| [0,17) | 단일 개체이나 이전 실험처럼 전체 이동/배율과 분리한 상대 동작이 약함. 제외. |
| **[7,24)** | **선정**. 단일 개체·컷/심한 가림 없음. 마지막 머리 회전이 몸통 기울임보다 커지는 순서가 보임. 세 후보 중 시간상 가장 이른 적합 구간. |
| [120,137) | 눈 감김/혀는 보이나 얼굴 확대여서 몸통·앞발 상대 배치가 보이지 않음. 제외. |

선정 구간 원본 시각은 7/24~23/24초, 새 영상 sample 시각은0~16/24초다. 17프레임24fps 파일 길이는17/24초다. 뒤쪽의 머리 roll은 도전적인 큰 변화로 숨기지 않는다. 다만 전신 spin/킥/컷/가림이 없고 정면 몸통·양 뒷발이 계속 보여 PLAN의 복잡한 전신 회전 회피 취지 안에서 선택했다. 이것은 쉬운 동작이라는 주장도, 머리 자세의 3D 정답도 아니다.

전처리: OpenCV RGB decode → INTER_AREA 512×288 → PIL BICUBIC 1592×896 → crop(540,0,1052,896). 같은 고정 canvas를 모든 프레임에 사용한다. 초기 display 시트의 첫 resize를 BICUBIC로 썼다가 기존 INTER_AREA 규칙에 맞춰 바로잡았다. 후보·시점·crop은 바뀌지 않았다. 현재 Mac decode는 과거 저장된 B006 RGB와 최대9 byte-level 차이가 있어 과거 RGB와 비트동일하다고 주장하지 않는다. 이번 실제 RGB를 두 조건의 공통 입력으로 고정한다.

source f7~16의 기존 비학습식 mask를 같은 crop에 재사용하고 f17~23은 수기 윤곽 seed와 CPU GrabCut3으로 준비했다. f19에서 잘못된 seed가 포함한 배경 쐐기를 한 번 수정했으며 v1을 비공개로 보존했다. 경계·발/꼬리·반사 분리의 불확실성은 PARTIAL이다. RGB 픽셀을 바꾸거나 새 얼굴/털을 만들지 않았다.

선정 시작13:19UTC, 마스크 생성13:25UTC경, 17장 시각검토와 입력복사13:29UTC경 완료. 45분 선정/30분 mask 상한 안이다. GPU 실행 전에 입력 hash와 다음 평가 계약을 고정한다.

# B-010 생성 전 관측성 판정

**DIAGNOSTIC_INSUFFICIENT — GPU P/PROBE/S/D 모두 NOT_RUN.** sampler 실패가 아니라 PLAN의 CPU 사전 중단 조건이다. source가 전혀 움직이지 않는다는 뜻은 아니다.

## 사전 고정한 관측

원본 f0/4/8/12/16의 코 중심·양눈 중심·양앞발 끝 표면 proxy 다섯 개를 사용한다. 해부학적 관절이나 발 접촉을 추정하지 않는다. B-006의 source-only 수동 관측을 재사용했고, 전체17프레임의 decodedRGB가 B-007 source와 정확히 같은지 검사했다. PNG 파일 해시는 달랐지만 RGB 배열은 같았다. 고정 resize1592×896, center crop512×896를 거친 RGB가 실제 driving MP4의17프레임과 정확히 일치했다. 좌표·이미지·마스크는 비공개로 보존한다.

불확실성은 기존 머리 표면점2픽셀, 앞발 표면점4픽셀에 고정 최대 축척896/288을 곱하고 표시/중심 좌표 양자화 여유1픽셀을 더했다. 이는 통계적 신뢰구간이 아니라 보수적 관측 오차 반경이다. 변위 오차는 두 시점의 반경 `u0+ut`로 계산한다. 새 생성물을 보고 점·시간·오차를 고르거나 줄이지 않는다.

선택 시점의 t>0 비교20개 모두 source에서 관측 가능했다(20/20). 숨은 관절·접촉은 UNKNOWN이며 평가에 추가하지 않았다. 생성 결과의 coverage는 NOT_RUN이다. 향후 대응점을 찾지 못하는 실패를 단순 제외해 점수가 좋아지게 하지 않는다.

## 실제 사전 값과 제한

고정 canvas 기준 정적 복사 변위 오차 평균 `E_copy=15.5106717544px`, 평균 관측 오차 `19.4222222222px`이다. 정규화 분모는 고정 canvas 높이896px이며 프레임별 재정렬이나 확대를 하지 않았다. `E_copy`가 오차보다 작아 gain은 **UNDEFINED**다. 임의 epsilon 또는 사후 유리한 부분집합으로 개선율을 만들지 않는다.

f8/12의 양눈과 f16의 코·양눈 절대 변위 일부는 각각의 오차를 넘는다. 따라서 제한된 머리 위치 변화는 실제로 관측됐다. 다만 이것만으로 전경 평행 이동·크기 변화와 articulated motion을 구분하지 못한다.

평행 이동과 공통 배율에 불변인 보조량으로 `코–양앞발 표면점 중점 거리 / 양앞발 표면점 사이 거리`를 계산했다. 중점은 신체 root나 관절이 아니다. 각 거리 오차를 보수적으로 전파한 범위는 모든 선택 시점에서 f0 범위와 겹쳤다. 이 비율은 f0 약1.2392, f16 약1.3267이며 f0 범위[0.9478,1.6499], f16 범위[1.0523,1.6985]다. 독립적인 앞발/머리 상대 움직임을 충분히 식별했다는 근거가 부족하다. 이 보조량을 맞추기 위한 영상 정렬·warp는 하지 않았다.

STATIC COPY는 원본 f0를 의도적으로17장 반복한 CPU 대조군이며17프레임·24fps다. 생성 output을 복제한 것이 아니고 생성 모델 호출은0회다. source/static 시트·주석 overlay·머리 확대를 실제로 열어 검토했다. 시간 품질은 연속 재생을 관찰하지 않았으므로 UNVERIFIED다.

## 고정 종료

이번 짧은 구간으로 정적 복사보다 나은 articulated motion을 엄격히 구별하기 어렵다. 따라서 더 긴 구간·다른 seed·다른 모델을 자동 실행하지 않고 CPU 자료를 보존해 종료한다. 입력 생성과 조건 코드 준비가 완료됐더라도 모델 추론 성공 또는 실패로 보고하지 않는다.

이 판정은 **기존 B-006 수동 관측을 확대 좌표로 전달한 현재 정밀도**에 한정한다. 이17프레임 자체가 어떤 정밀도의 관측으로도 쓸 수 없다는 증거는 아니다. 다음 제안은 같은17프레임의 native512×896 표면점을 새로 수동 관측해 오차를 평가하는 CPU 작업 하나이며 이번에는 실행하지 않았다.

# C-002 결과 — 윤곽의 거친 진행 제어와 남은 동작 한계

**차량은 TRADE_OFF, 개는 COARSE_CONTROL_ONLY다. 기본 채택하지 않는다.** MOV는 STILL보다 원본의 거친 진행을 더 따랐다. 개는 ENDPOINT보다도 정면 접근이 일찍 나타났다. 차량은 중간 크기·진행의 일부 이득과 보호 장면의 손상을 함께 보였다. 내부 자세·접촉의 정확한 전이는 입증하지 못했다. 네 신규 영상은 모두 정상 생성됐지만, 실행 성공을 결합 품질 PASS로 해석하지 않는다.

## 비교 범위와 근거

기존 C-001 ENDPOINT 두 개와 동일 source·reference·네 앵커를 재사용했다. 순서는 차량 MOV → 차량 STILL → 개 MOV → 개 STILL이다. 신규 영상마다 33프레임, 50 scheduler step, 100 model_fn call이다. 입력 SAM 재추론·imagegen·학습·다운로드·설치·품질 재시도·기계적 복구는 모두 0회다. SAM의 기존 source 윤곽을 실제 중간 RGB 조건으로 썼으므로 이번에는 SAM layout-conditioned라고 부를 수 있다. 원본 중간 RGB나 SAM overlay를 생성 입력으로 사용하지 않았다.

실행 전 코드/계획 공개 SHA는 `66223092db021fbbdbbc49aec02b6fd2c431a0d3`, 부모 C-001은 `5ba0cdbe4a11bb35ae77ce638acbbcc501e90da2`다. 설정과 렌더링은 [CONDITIONS](CONDITIONS.json), 실제 관측은 [NUMERICS](NUMERICS.json), 비용은 [COSTS](COSTS.json)에 있다. 고정 인덱스 0/4/8/12/16/20/24/28/32와 네 신규 영상의 전체 33장을 실행자/독립 검토자가 정적으로 보았다. 자동 시간 정렬·공간 정합 없이 같은 인덱스를 비교했다. 132프레임을 132개 독립 사례로 세지 않는다.

## 차량 — TRADE_OFF

| 판정 축 | 실제 관측 |
|---|---|
| 위치·크기 | MOV의 중간 대상 크기/범위는 ENDPOINT보다 source에 가까워 보이는 구간이 있다. STILL은 초기 크기·옆모습을 오래 유지한다. 출력 segmentation 수치로 검증한 주장은 아니다. |
| 거친 방향·실루엣 | MOV는 후면 노출과 축소가 점진적으로 나타나 STILL보다 source 진행에 가깝다. 다만 local16에서 source보다 후면이 일찍 보여 회전 타이밍의 정확한 개선은 확정하지 않는다. |
| 시간별 진행 | STILL은 대략28까지 초기 상태에 머물고 29–32에서 늦은 형태 전환이 보인다. MOV의 거친 진행 이득은 있으나 ENDPOINT 대비 결합 개선은 확립하지 못했다. |
| 내부 동작 | 바퀴 회전·정확한 차체 회전량은 UNCERTAIN이다. |
| target 외형 | 은색 높은 차체·세로 후미등 등은 전체33장에서 대체로 남고, 뚜렷한 Mini 복귀는 보이지 않는다. 루프레일·창 세부와 정확한 차종 정체성은 PARTIAL이다. |
| 양끝 앵커 | 양끝 출력을 덮어쓰지 않았다. 대략적인 편집 외형은 남지만 pixel-exact 앵커 충실도는 아니다. |
| 보호 장면 | 빨간 전경 차량이 source 약24보다 훨씬 일찍 등장한다(STILL 약5, MOV 약8). source16의 파란 원형 방향 표지판은 재현되지 않는다. 배경 카메라/기념물/차량 진행도 달라진다. |
| 형태·접촉·그림자 | STILL29–31의 흐림/변형이 보인다. 미세 바퀴 경계·접촉·그림자 일치는 UNCERTAIN이다. |
| 연속 품질 | temporal=UNVERIFIED. 정적 전체 프레임 검토와 파일 재생 가능성만 확인했다. |
| 비용 | MOV 288.865초, STILL 290.845초의 실제 worker 실행. 각각50step/100call. |

ENDPOINT↔MOV는 중간 구조 조건을 추가한 전체 효과다. ENDPOINT↔STILL은 초기 구조를 반복하자 진행이 오래 정체되고 장면도 달라진 사례다. MOV↔STILL에서는 움직이는 윤곽의 거친 진행 제어가 보이지만, 보호 장면 손상 때문에 USEFUL_MOTION_GAIN으로 올리지 않는다.

## 개 — COARSE_CONTROL_ONLY

| 판정 축 | 실제 관측 |
|---|---|
| 위치·크기 | MOV가 ENDPOINT의 옆모습/낮은 머리 정체와 STILL의 거의 고정된 위치보다 원본의 정면 접근에 가까워진다. |
| 거친 방향·실루엣 | local8/16에서 정면으로 돌아오며 앞발을 내미는 상태가 더 일찍 나타난다. 원본의 거친 접근 방향과 진행이 개선된다. |
| 시간별 진행 | STILL은 약1–29에서 거의 초기 자세를 유지한다. MOV는 전체33장에서 접근·방향 변화가 더 지속적으로 보인다. |
| 내부 자세·발디딤 | 머리는 여전히 낮고, 정확한 교대 보행 위상·관절 대응·발 접촉은 UNCERTAIN이다. 윤곽에 없는 내부 동작을 맞췄다는 증거는 없다. |
| target 외형 | 검정/흰 털, 얼굴의 흰 무늬, 흰 발이 대체로 남고 원본 크림색 개로 뚜렷하게 돌아가지 않는다. 정확한 target 체형·털·꼬리·개체 정체성은 확인하지 못했다. |
| 양끝 앵커 | 종료 앵커의 낮은 몸/머리와 앞발 뻗음은 원본의 더 선 자세와 충돌한다. MOV의29–32도 이 충돌 때문에 원본 대비 평가에 한계가 있다. |
| 보호 장면 | 울타리·수풀·잔디의 큰 구성은 남는다. 질감과 배경 움직임은 달라지며 완전 보존 PASS는 아니다. 정적 검토에서 차량 같은 추가적인 큰 장면 손상은 뚜렷하지 않았다. |
| 형태·접촉·그림자 | STILL30에서 심한 형태 변형/분절이 보인 뒤 종료 상태로 전환된다. MOV의 발·꼬리·얼굴 세부 및 접촉 그림자도 정확성을 보장하지 않는다. |
| 연속 품질 | temporal=UNVERIFIED. 연속 지각 검수를 수행했다고 보고하지 않는다. |
| 비용 | MOV 292.674초, STILL 292.159초의 실제 worker 실행. 각각50step/100call. |

ENDPOINT↔MOV와 MOV↔STILL 모두 거친 접근 진행의 이득이 보인다. ENDPOINT↔STILL에서는 초기 구조 반복이 동작을 더 정체시킨다. 그러나 머리·관절·접촉이 미해결이고 종료 앵커도 충돌하므로 완전한 동작 전이 성공은 아니다.

## 실제 조건 전달과 운영 결과

네 실행의 실제 첫 noisy latent는 BF16 `[1,16,9,60,104]`이며 원바이트 SHA256이 모두 `cf71cc3501ff09f876a384a20e9aedea41fb7eaaf956e5da52e8f777c9fbf9ba`로 같았다. 같은 사례 MOV/STILL의 실제 VACE context `[1,96,9,60,104]` 해시는 다르고 유한값이었다. 실제 mask64채널은 같은 해시, 시간9개 평균 모두1, effective scale1.0이다. 원래 첫 함수 직전에 관측했고 추가 forward는0이다. 이 차이는 전달 증거이지 조건 활용의 품질 증거가 아니다. C-001의 최초 noise는 관측 자료가 없으므로 과거 bitwise 동일성을 주장하지 않는다.

기존 C-001 guard와 adapter는 변경하지 않았다. 네 CPU systemd 경로와 네 heavy 모두 COMPLETE, 최종 CLEAR, 정상 종료/자원 회수 확인, cleanup 오류0이다. 관측 최저 MemAvailable은88.09GiB, 자체 swap.current/max는0, high/oom/oom_kill 이벤트0이었다. 시스템 swap1,040,384bytes는 계속 그대로였으며 GLOBAL_SWAP_WARNING을 남겼다. 관측 PSI full 최대 비율은4e-7로 작은 비영 값까지 보존했다. 한도를 높이거나 타 작업을 종료하지 않았다. 종료 후 cgroup 상태는 REMOVED로 기록하며 swap0으로 위조하지 않는다.

## 해석의 한계와 다음 하나

두 사례·한 seed이며 source silhouette에는 체형 정보도 포함된다. 원본 체형 유입, 앵커와 구조의 충돌, 새 조합의 분포 차이, 조건 활용 부족은 가능한 설명이다. 어느 하나를 원인으로 확정하지 않는다. STILL과 종료 앵커의 충돌도 달라지므로 MOV/STILL 차이를 순수한 시간 인과효과라고 부르지 않는다. SAM의 차량 미세 speckle도 필터링하지 않았고, 경계/접촉은 정답 annotation이 아니다.

다음 논의 후보는 **객체 내부 대응: 머리와 팔다리의 시간별 대응점** 하나다. 개의 거친 접근은 개선됐지만 내부 자세가 해결되지 않았기 때문이다. 이는 다음 설계 논의이며 모듈·학습·추가 GPU 실행을 시작하지 않았다. source 체형 회귀가 확정되지 않았으므로 target-aware 변환의 필요성을 이번 결과로 입증했다고 주장하지 않는다. C-001 PARTIAL/UNVERIFIED와 A/B 실패·보류는 그대로 유지한다.

검토 ZIP은 source/reference/anchors, 생성 결과 원 MP4 여섯 개(ENDPOINT2+신규4), 조건/SAM preview, 전체33장 JPEG 비교와 동일 crop, 보고서를 포함한다. JPEG/조건 preview는 검토 파생본이고, 원 생성 MP4는 재인코딩하지 않았다. Raw/latent/무손실 전체 프레임은 Spark의 별도 full에 보존했다. 실제 전송/CRC/추출/해시는 [DELIVERY](DELIVERY.json)에 기록한다.

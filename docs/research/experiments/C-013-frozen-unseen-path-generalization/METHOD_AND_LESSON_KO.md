# C-013 실제 결과로 읽는 방법과 교훈

Y=H(A0,AT,P,Q;epsilon,theta,psi)에서 양끝 앵커A0/AT, 공유 point 정보P, noise epsilon, backbone theta, 동결 adapter psi를 고정하고 Q만 바꿨다. 실제 first-model trace에서 noise·전체96채널 context·text·앵커·공유 field 일치를 확인했다. 그러므로 새 네 출력의 차이를 좌표 변경과 연결할 수 있다.

좌표 보간은 Q를 섞어 한 번 생성하는 것이다. 두 완성 영상의 픽셀을 섞는 후합성과 다르다. 두 공의 평균 중심이 중간인 것도 새 좌표 제어가 아니다. 그래서 전체화면 template reader의 단일성·duplicate와 정적 외형을 별도로 확인했다. 전33프레임 검출은 정상이지만 S의 흐린 겹친 윤곽은 외형 결함으로 남는다.

보간은 같은 위/아래 진폭 계열의 세 중간 좌표다. S는 아래→중앙→위라는 시간 순서 변경을 요구한다. 이번 실측은 둘 다 기준을 통과했다. 공간 범위는 학습 A/B 안이며 임의 속도·회전·가림·다른 물체까지 확인한 것은 아니다.

E_req는 요청 좌표 오차, E_mem은 시점별 더 가까운 학습A/B까지의 거리다. 네 경로에서 E_req+4≤E_mem이므로 단순 A/B 쪽 attraction보다 요청 추종의 근거가 있다. 반대로 A/B에 가까웠더라도 내부가 정확히 두 영상을 저장한 분류기라는 증명은 되지 않는다.

고정 noise의 경로 일반화와 다른 seed에서의 품질 일반화는 별개다. seed1 새 경로는 성공했지만 seed2 장면 보존 문제는 여전히 크다. 같은 seed의 BASE bypass와 ON을 비교해야 noise 차이를 원인으로 혼동하지 않는다. 실제 BASE2도 심각하게 무너졌으며 ON은 손상을 바꾸고 평균 배경오차를 줄였지만 배경을 복원하지는 못했다. 따라서 MIXED_BASE_ADAPTER_EFFECT이며 adapter 무영향이나 단독 원인으로 단정하지 않는다.

위치·단일성·무늬/형태·잔해·배경·시간은 따로 판단한다. 정확한 중심과 낮은 검출 누락이 완전한 외형 보존을 뜻하지 않는다. 재생 가능과 정적 프레임 관측도 연속 지각 검수가 아니므로 temporal=UNVERIFIED다. 같은 세션의 이미지 검토는 독립 human 평가가 아니다.

다음에 바꿀 요소 하나는 보호 배경 보존 제약이다. 현재는 동일 두 영상의 추가 과적합보다 제어 능력을 유지하면서 보존을 따로 평가할 이유가 생겼다. 새 학습·seed·외부 모델 실행을 예약하거나 시작하지 않았다. 이전 중단 기록과 C-012의 seed 민감 판정도 소급 변경하지 않는다.

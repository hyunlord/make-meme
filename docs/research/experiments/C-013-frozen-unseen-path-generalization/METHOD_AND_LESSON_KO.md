# C-013 방법 해설: 관측되지 않은 결과를 채우지 않기

이번 실험은 안전 admission에서 멈췄다. 아래는 고정한 질문의 의미이며 성공 설명이 아니다.

Y=H(A0,AT,P,Q;epsilon,theta,psi)에서 A0/AT는 양끝 앵커, P는 endpoint patch·유효성 등 공유 점 정보, Q는 시간별 좌표, epsilon은 noise, theta는 backbone, psi는 동결 adapter다. Q만 바꾸면 같은 장면·noise·모델에서 좌표 변화의 효과를 비교할 수 있다. 실제 C-013의 입력 parity는 생성 전 중단으로 아직 확인하지 못했다.

좌표 보간 Q_alpha=(1-alpha)Q_A+alpha Q_B는 모델 입력의 위치를 바꾼다. 이미 만든 두 영상의 픽셀을 섞는 것은 출력 후합성이며 다른 연산이다. 두 공이 나타났는데 평균 중심이 중간인 경우도 원하는 위치에 같은 단일 공이 생긴 증거가 아니다. 그래서 전체화면 reader의 duplicate 판정과 형태 검토를 위치 오차와 함께 요구한다.

I25/I50/I75는 같은 진폭 계열 안의 세 입력이다. S는 시간에 따라 아래→가운데→위로 방향이 바뀌어 학습한 두 곡선의 단순 선택보다 더 다른 순서를 요구한다. 공간 범위는 여전히 A/B 안이다. 성공하더라도 일반 경로·속도·회전·가림·동물 편집까지 확장할 수 없다.

E_req와 E_mem은 요청 경로에 가까운지 학습 A/B에 가까운지의 출력 기하 검사다. A/B attraction이 관측되더라도 내부가 두 영상을 정확히 암기한 분류기라는 메커니즘 증명은 아니다. 이번 값은 출력이 없어 null이다.

고정 noise의 새 Q 성공은 경로 일반화이고, 다른 noise에서도 같은 품질을 보이는 것은 seed 일반화다. C-012 seed2의 배경 붕괴를 가르려면 동일 noise/context/text/앵커에서 실제 BASE bypass와 ON을 비교해야 한다. BASE도 나쁘다고 adapter 무영향이 되는 것은 아니다. 양쪽 손상 위치와 정도의 차이를 따로 보고해야 한다. 이번 BASE_S2가 없어 원인은 여전히 INCONCLUSIVE다.

위치·단일성/무늬/형태·잔해·배경·시간 품질은 다른 축이다. 정확한 중심은 장면 보존이나 시간 안정성을 보장하지 않는다. ffmpeg decode나 프레임 측정으로 연속 지각 품질을 대신하지 않는다. 이번 temporal은 UNVERIFIED다.

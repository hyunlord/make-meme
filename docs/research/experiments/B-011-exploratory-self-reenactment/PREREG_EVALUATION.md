# B-011 생성 전 평가 계약

**수준 A: OBSERVABLE_SCREEN_CHANGE / 탐색적 1회 생성 GO. 수준 B: INCONCLUSIVE.** 입력·안전 gate는 별도 유지한다. B-010의 DIAGNOSTIC_INSUFFICIENT와 사용0회 기록은 변경하지 않는다. 이번 GO는 명시적으로 바뀐 B-011 탐색 범위에 따른 판단이며 정밀도 수치를 줄여 얻은 PASS가 아니다.

## 실제 관측 방법

동일 source f0/4/8/12/16 다섯 장을 `view_image`로 실제 열어 보았다. native512×896 화면에 좌표 눈금을 표시하고, 고정된 머리·앞발 crop을 nearest로 표시 확대했다. 이전 관측점 overlay는 현재 panel에 포함하지 않았다. 다만 같은 에이전트가 B-010을 이미 보았으므로 완전 blind/독립 관측이라고 부르지 않는다. 좌표는 이미지에서 읽어 텍스트로 기록했다. 실제 마우스 클릭이나 사람 검수를 했다고 주장하지 않는다.

선택점은 코의 어두운 표면 중심, 양눈 중심, 양앞발의 보이는 말단 발가락 묶음 중심이다. 해부학적 관절·숨은 점·발 접촉은 UNKNOWN이다. 원본은512×288에서 확대된 입력이며 새로운 고해상도 정보가 생긴 것이 아니다. 보간 주석·새 점·더 좋은 구간은 추가하지 않았다. 개인 좌표는 비공개 기록에만 있다.

## 오차와 반복 판독은 별도

기존 반경은 그대로 유지한다: 머리 `2×(896/288)+1=7.2222px`, 앞발 `4×(896/288)+1=13.4444px`. 두 시점 변위의 반경은 `u0+ut`이고20항목 평균은19.4222px다. 실측 RMSE·표준편차·95% CI가 아니다. 같은 f0를 공유하므로 독립 표본 검정도 하지 않는다.

현재 판독과 이전 판독의 차이: 머리 평균2.5607px/최대5.3663px, 앞발 평균5.6347px/최대9.6269px. 이는 같은 에이전트의 판독 차이이며 정확도나 신뢰구간이 아니다. systematic bias는 UNKNOWN이다. 이 차이가 작다는 이유로 기존 반경을 줄이지 않는다.

현재 source의20개 변위 평균16.5407px와 기존 반경합 평균19.4222px를 나란히 남긴다. 머리12항목 평균18.0420px/반경합14.4444px, 앞발8항목14.2887px/26.8889px다. 일부 머리 화면 변화는 정적 복사와 다르게 관측된다. 머리는 초기에서 중간까지 화면 위쪽·약간 왼쪽으로 움직인 뒤 마지막에 오른쪽으로 돌아오는 위치 변화가 보인다. 앞발의 정밀한 상대 동작은 불확실하다. 이 그룹 구분은 생성 전에 고정하며 B-010의 이전 측정값을 덮어쓰지 않는다.

## 출력 평가를 지금 고정

- 모든17프레임을 source/STATIC COPY/새 출력의 같은24fps 시간축으로 비교한다. B-009는 맥락만 표시한다.
- 정량 좌표는 위의 고정5시점×5표면점만 읽는다. 보이지 않거나 형태가 무너져 대응이 불가능하면 null/invalid로 남기고 전체25개 위치 및20개 변위 분모를 유지한다. 좋은 점만 남겨 전체 점수가 좋아진 것처럼 보고하지 않는다.
- source와 output 모두 `q(t)=p(t)-p(0)`를 계산하며 고정 정규화 크기는896px다. 전 프레임 공통 좌표계를 유지하고 사후 warp/zoom/lag/time alignment는 금지한다.
- source E_copy 분모가 현재 보수적 오차에 묻히므로 통합 gain은 **UNDEFINED**로 고정한다. 대신 raw 변위·오차·coverage와 전체 시각 비교를 제출한다. 머리의 좋은 부분집합으로 통합 gain을 대신하지 않는다.
- 수준 A는 단순 reference 복사, source와 대응하는 이동/크기/머리 변화, source와 무관한 흔들림을 구분한다. 직립 유지·선명함·움직임 크기만으로 motion 성공을 선언하지 않는다. 가능한 결론은 source 변화 재현 근거 있음/STATIC_COPY_LIKE/STRUCTURE_FAIL/INCONCLUSIVE이며 근거를 명시한다.
- 수준 B는 기존 코–앞발 중점 거리/앞발 간격 같은 상대 표면량과 부위 방향을 보조로 읽는다. 이는 관절이나 body root가 아니다. global translation/scale만의 변화는 articulation 증거가 아니며 현재 source 상대 신호가 불확실하면 계속 INCONCLUSIVE다.
- 특정 개체 동일성과 품종·외형 유사성을 분리한다. cross-identity·물리 접촉·일반화·Lab/IG 안무 수용은 NOT_RUN이다.
- 실제 속도 연속 영상을 관찰하지 않으면 temporal=UNVERIFIED다. 정적 시트나 HTML play 이벤트는 연속 시청이 아니다.

완전히 정적인 source 또는 입력/안전 위반은 중단 조건이지만 현재 source는 완전히 정적이지 않다. 따라서 관측의 불확실성을 결과에 유지하면서 명시된 탐색1회를 진행할 수 있다. 생성 후 판독 정밀도를 추가로 조정하거나 기준을 바꾸지 않는다.

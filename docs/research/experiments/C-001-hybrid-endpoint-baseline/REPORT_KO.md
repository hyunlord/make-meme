상태: 실행 중. 이 파일의 준비·CPU 성공은 영상 품질 성공이 아니다.

## 사전 고정과 보존

사전 계획·입력 고정 commit은 `4ea7753`이며 native imagegen 전에 push했다. B 연구 기록과 환경은 변경하지 않았다. 두 사례는 DAVIS car-roundabout30..62→car-shadow0, dog0..32→dog-gooses85다. source FPS는 알 수 없어 미리보기16fps만 부여했다. 새 앵커 네 장은 실제 내장 imagegen 결과이며 raw 원본·프롬프트·해시를 보존했다. 자세한 기계 판독 기록은 `INPUTS.json`, 각 `*-editspec.json`, `ANCHORS.json`에 있다.

## 운영 기록

실제 systemd CPU 진입에서 실제 앵커 조건33장 검사 및 CUDA 미초기화가 확인됐다. 첫 CPU 시도의 최종 supervisor 영수증은 `OBSERVATION_FAILED`였으며 성공으로 덮어쓰지 않는다. GPU 전 종료 관측 경로를 수정·재검증한다. 이 CPU 실패는 모델 품질이나 모델 OOM 결과가 아니다.

## 실제 영상 결과

PENDING — 실제 영상 생성 및 자원 회수 뒤 각 결과를 기입한다. 생성 여부, endpoint 충실도, 중간 target 외형, 동작 순서, 보호 장면, 경계·접촉·그림자를 분리한다. 연속 지각 검수가 없으면 temporal=UNVERIFIED다.

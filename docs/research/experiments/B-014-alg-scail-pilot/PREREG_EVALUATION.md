# B-014 출력 열람 전 평가 고정

대상은 기존 B-012에서 선정한 source f7~23과 기존 B-013 LAB_MOV/LAB_STILL, 새 LAB_MOV_ALG 한 결과다. reference/task/입력 조건은 B-013 LAB_MOV와 동일하고 sampling의 초기 reference guidance만 계획대로 바꾼다. baseline 결과는 재생성하지 않는다.

전체17장과 local0/12/14/16을 같은 canvas·시간축에서 본다. source방향·증가순서·몸통 대비 상대 변화가 핵심이며 더 큰 변화량이나 선명한 정지만으로 이점을 판단하지 않는다. 별도 warp·crop·안정화·보간·선별·속도변경은 없다. 정확한 각도·접촉을 관측할 수 없으면 UNCERTAIN이며 가려진 점을 채우지 않는다.

| 축 | 관측 기준 | 수용하지 않는 대체 판단 |
|---|---|---|
| 전신 | 뒷발 직립과 가슴 앞에 든 앞발인가, 참조의 착석인가 | 머리만 움직임/상체 이동을 직립 성공으로 올림 |
| 국소 | local12/14/16의 원본 후반 roll 방향·순서·머리-몸통 상대배치 | 원본과 다른 흔들림·zoom·붕괴의 변화량 |
| 얼굴·귀 | B013MOV의 후반 눈/주둥이/귀 번짐과 비교, 모든실패프레임포함 | 좋은 프레임만 비교, STILL 정지의 선명함만 최종점수로 사용 |
| 개체·체형 | 실제 Lab 얼굴·귀·주둥이/넓은가슴·굵은사지, source외형누수 | 검은Lab견종 유사성을 실제개체 보존PASS로 대체 |

| 시간 | 실제native24fps 연속시각검토 여부명시 | MP4존재/브라우저play이벤트를 시간품질PASS로 바꿈 |

기술실행 PASS, ALG연결 PASS, 전신/국소/형태/개체 수용은 각각 분리한다. 앉은채로국소가개선되면 전신FAIL과국소개선을 함께기록한다. blur만악화하면움직임성공으로세지않는다. 정밀출력오차가보정되지않았으므로 gain·유의성·임의정량성공지표를만들지않는다.

비용은 baseline80 대 ALG88forward, 실제Swalltime/step과memory를 별도로비교한다. NFE+10%를walltime+10%나공정한compute-matched우월성으로부르지않는다. 한seed·한설정pilot이며 후속ALG_STILL/seed/강도탐색/학습을자동시작하지않는다.

## 비차단 provenance 주의

[phase_encode.py:67](https://github.com/hyunlord/make-meme/blob/9a93aa09ed2032aebea3905e5b698388b65243c4/docs/research/experiments/B-027-public-reference-robustness/code/phase_encode.py#L67)에서 만든 `provenance.preprocessed_inputs`는 R1의 실제 전처리 관측이다. [phase_encode.py:94](https://github.com/hyunlord/make-meme/blob/9a93aa09ed2032aebea3905e5b698388b65243c4/docs/research/experiments/B-027-public-reference-robustness/code/phase_encode.py#L94)의 R2 metadata는 이를 계승하면서 R2 config·RGB/mask 파일 해시·parent cache·reference-only 재인코딩 표지를 별도로 기록한다.

따라서 이 필드를 **R2 normalized-image의 별도 실측값으로 인용하면 안 된다**. R1 capture 계보로 설명하고, R2 입력은 명시적 R2 파일 해시와 config, 새 reference tensor 해시, pair 조건 비교를 근거로 구분한다. 이 검토에서는 해당 metadata나 실행 코드를 수정하지 않았다.

## 검토 한계

이 문서는 코드 연결과 검사 위치의 확인이다. 실제 runtime receipt의 통과, 보호 정책의 실제 발동 여부, 출력 외형·동작·시간 품질을 대신하지 않는다. 개인 미디어·조건 tensor·latent·개인 절대 경로는 포함하지 않았다.

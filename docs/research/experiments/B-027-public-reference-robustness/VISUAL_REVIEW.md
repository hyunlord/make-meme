# B-027 agent 정적 관측

관측자는 실행 agent이며 독립 사람 평가가 아니다. local0/8/16 full-canvas 비교와 전체17장 시트를 근거로 축별 판독을 기록한다. 실제 속도 연속 시청에 의한 시간 품질은 전 조건 `UNVERIFIED`. 아직 관측하지 않은 출력은 미리 판정하지 않는다.

## animal R1 — 첫 실제 출력

- **Target 외형 FAIL:** 참조의 어두운 털과 흰 부분보다 source의 옅은 크림색 개 외형이 남는다. 작은 참조의 세부 identity 판독 한계와 별개로 밝음/어두움이라는 사전 특징부터 맞지 않는다.
- **동작 PARTIAL:** local0에서 고개를 낮춘 측면에 가까운 모습, local8의 접근, local16의 더 정면인 모습이라는 큰 순서는 source와 대응한다. 앞발 교대의 정확성·접촉은 불확실하다. 이 관측으로 독립적인 motion 전이 성공을 선언하지 않는다.
- **장면 FAIL/PARTIAL:** 울타리·오른쪽 관목·잔디의 큰 배치는 남지만 하단 왼쪽에 원본과 참조에 없던 큰 문자/문양과 장식판 같은 영역이 생긴다. 합당한 새 개 실루엣에 따른 가림으로 설명할 수 없다.
- **형태 PARTIAL/UNCERTAIN:** 머리·털·다리의 세부가 source보다 부드럽고 뭉개진다. 눈/발끝의 정확한 구조는 판독 한계가 있다. 대상 개체 일치 PASS는 아니다.
- **주의:** 첫 출력의 시각 실패는 같은 task R2를 생략할 기술·안전 사유가 아니다. 필터·마스크·caption을 바꾸지 않고 고정된 비교를 계속한다.

## animal R2와 pair

- **Target 외형 FAIL:** R2도 어두운 target이 아니라 옅은 source 개가 남는다. 두 사진의 자세/크기를 바꾸어도 이번 입력에서는 identity-changing 교체를 입증하지 못했다.
- **동작 PARTIAL:** 전체17장에서 접근 방향과 정면으로 향하는 큰 변화는 source와 대응한다. 정지 참조 복사 형태는 아니지만 정확한 발 위치/접촉·미세 timing은 UNCERTAIN이다.
- **장면 PARTIAL:** R1의 거대한 문자 장식은 R2에 보이지 않는다. 울타리·관목·잔디 배치는 대체로 남고 source보다 흐리다. 장식이 없다는 것만으로 target 교체가 성공한 것은 아니다.
- **형태 PARTIAL/UNCERTAIN:** 개의 전신은 남지만 얼굴·털의 세부가 무르고 일부 다리 윤곽이 가늘게 정리된다. target의 검은 털·흰 악센트·실제 개체 일치는 FAIL/미입증이다.
- **Pair 해석:** 참조 묶음 변화가 불필요한 장식 생성에는 영향을 줬지만 유용한 target 외형 반영은 두 조건 모두 실패다. 작고 멀리 배치된 참조, 시점과 support 차이를 따로 기록하며 그중 하나를 유일한 원인으로 확정하지 않는다. 실제 연속 시청은 하지 않았으므로 temporal UNVERIFIED다.

## human R1

- **외형 반영 PARTIAL:** source의 남색/회색 짧은 의상·밝은 묶은 머리에서 흰 블라우스·넓은 연분홍 치마·어두운 머리로 바뀐다. target 의상/머리 특징이 반영되는 근거는 있지만 얼굴이 흐려 실제 인물 일치는 UNCERTAIN이다.
- **동작 PARTIAL:** 앞쪽 교차 스텝→두 발이 가까운 중간 상태→후반 넓게 벌린 다리라는 큰 배치는 대응한다. 초기 source의 머리 뒤 팔/허리 쪽 팔 배치와 출력의 넓게 펼친 팔은 다르고, 팔 내림·손 방향의 정확한 타이밍은 미입증이다. 커진 치마의 퍼짐과 흔들림을 source 동작 성공으로 세지 않는다.
- **형태 PARTIAL/FAIL:** local8 얼굴·팔/손과 local16 머리/상체가 크게 부드럽거나 번진다. 넓은 치마에 가린 다리는 숨은 정답으로 채우지 않는다.
- **장면 PARTIAL/FAIL:** 관객·포장면·뒤쪽 큰 더미의 전체 배치는 남지만 좌하단에 source/reference에 없던 흰 서명 모양이 생긴다. 새 옷의 합당한 가림과 무관한 문양 추가를 구분한다.
- **관측 명칭 정정:** 사전 CASES의 보호영역 중 `돌담`은 이미지 판독 오인이었다. 실제 배경은 둥글게 쌓인 건초/짚 더미로 보인다. 원본 프레임·mask·caption·평가 위치는 바꾸지 않으며 과거 사전 표현을 숨기지 않는다.

## human R2와 pair

- **외형 반영 PARTIAL:** R2도 흰 상의·분홍 테두리 치마·어두운 머리로 바뀐다. 옷의 큰 차이는 반영되지만 정확한 얼굴 identity는 UNCERTAIN이다.
- **동작 PARTIAL/FAIL:** 교차한 다리에서 뒤쪽 넓은 스텝으로 가는 큰 순서는 남는다. 그러나 초기 팔을 넓게 든 모습과 크게 열린 치마가 R2 reference에 더 가깝고, source의 팔/상체 배치와 다르다. 정지 복사는 아니지만 source 안무를 충실하게 따른다고 할 수 없다.
- **형태 FAIL:** 후반으로 갈수록 치마가 위로 올라와 상체/얼굴 주변을 크게 가리고 몸과 옷의 연결이 불안정하다. local16의 발 부근에는 source/reference와 다른 어두운 형태도 보인다. 가려진 관절의 정답을 추정하지 않는다.
- **장면 PARTIAL/FAIL:** 관객·포장면·건초 더미의 큰 배치를 유지하지만 R1과 다른 흰 서명/문자 모양이 좌하단에 추가된다. 실제 옷의 넓어진 가림과 별개인 비편집 영역 훼손이다.
- **Pair 해석:** 두 참조 모두 target 의상 반영이 있지만 치마의 펼쳐진 방향·상체 가림이 다르다. reference-bundle에 민감하며, source의 큰 다리 변화와 reference의 공간 배치가 함께 영향을 주는 탐색적 근거다. 순수 pose 인과효과나 일반화 성공은 아니다. R2 GT의 관목 가림도 입력 한계로 남아 있으며 이 하나를 실패의 확정 원인으로 삼지 않는다.

## vehicle R1

- **외형 반영 PARTIAL / 실제 target 교체 FAIL:** 은색과 검은 옆 몰딩은 target과 대응하지만 source의 Mini형 차체·창·바퀴 배치가 강하게 남는다. 참조의 높은 각진 차체·긴 세로 후미등·루프레일을 갖춘 차량으로 정확히 바뀐 것은 아니다. 색상 변화만으로 instance 교체 PASS로 보지 않는다.
- **동작 PARTIAL:** 전체17장에서 오른쪽 진행과 측면→뒤쪽3/4 변화, 카메라 추적에 따른 배경 이동은 source와 큰 순서가 대응한다. 정확한 바퀴 회전·접지·물리적 속도는 UNCERTAIN이다.
- **장면 FAIL:** 도로·건물·난간의 배치는 대체로 남지만 좌하단에 원본/참조에 없는 빨강·흰색의 장난감 스포츠카 같은 큰 그래픽이 전 프레임에 추가된다. 대상 차체가 커져 가린 영역과 무관하다.
- **형태 PARTIAL:** 주 차량은 연속된 차체로 보이나 바퀴/앞뒤 세부가 변형되고 source/target 특징이 혼합된다. 새로운 그래픽은 target의 두 번째 유효 개체로 인정하지 않는다.
- **한계:** 공개 강체 사례 한 건이며 모델의 모든 강체 지원 범위를 단정하지 않는다. 입력 크기·시점·모델 도메인의 영향을 분리한 실험도 아니다.

## vehicle R2와 pair

- **외형 반영 PARTIAL / 정확한 target 미입증:** 은색에 가까운 밝은 차체와 높은 박스형 창/지붕 비율로 변한다. R1보다 옆 검은 몰딩이 약하고 target R2의 밝은 rear3/4 인상과 일부 대응한다. 그러나 source형 바퀴·차체 요소가 남고 target의 긴 세로 후미등·루프레일·창 구조를 충실하게 재현한 것은 아니다. 단순 흰 차가 된 것을 실제 target instance 일치로 올리지 않는다.
- **동작 PARTIAL:** 오른쪽 진행과 후반 더 보이는 후면 방향은 source의 순서를 따른다. reference의 왼쪽 진행 방향을 그대로 복사한 정지 영상은 아니다. 바퀴 회전과 접지, 원래 초 단위 속도는 UNCERTAIN이다.
- **장면 PARTIAL:** R1의 좌하단 그래픽은 없다. 건물·난간·다른 차의 큰 배치는 남지만 세부 표지/질감은 부드럽고 달라진다. 깨끗해 보이는 R2가 R1의 실패를 취소하지 않는다.
- **형태 PARTIAL:** 전신 차체는 유지되지만 source/target과 다른 혼합 형상이며 앞뒤 램프와 휠의 세부 충실도는 낮다. 큰 형상 연속성의 정적 근거와 실제 속도 시간 품질을 구분한다.
- **Pair 해석:** 두 참조가 색·몰딩·차체 인상·불필요한 그래픽 발생에 영향을 준다. target의 실제 차종/개체 일치까지 보장하지 않으며 더 작은 R2가 일부 장면에서 낫다는 사실만으로 크기 감소의 인과효과를 주장하지 않는다.

## 전체 패널의 결론

6개 실제 raw를 모두 전체17장과 local0/8/16에서 확인했다. 동물은 source 외형 잔존, 사람은 의상 반영과 참조 배치/형상 문제, 차량은 부분 recolor/혼합 형상과 조건별 장면 훼손으로 나뉜다. 이것은 SCAIL의 보편 객체 교체 성공을 입증하지 못한 탐색 패널이다. frame sheet 검토와 브라우저 재생 가능 검사는 사람의 연속 시청이 아니며 모든 temporal 판정은 UNVERIFIED다.

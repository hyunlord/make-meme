# C-014 수식·코드·결과의 연결

이전 C-013은 생성 영상 전체를 평가했다. 이번에는 생성 Y를 그대로 개선한 것이 아니라 이미 관측한 배경 B를 사용해 시스템 출력 C를 만든다. 그래서 배경이 깨끗해져도 모델이 새로 배경을 생성하는 능력을 얻었다고 말하지 않는다.

C=alpha·Y+(1−alpha)·B. 요청 중심에서44px 이내 alpha1이므로 RAW byte가 그대로 남고,52px 바깥 alpha0은 B의 같은 좌표를 복사한다. 사이8px만 cosine으로 혼합한다. float64 RGB code값 혼합 후 np.rint/clip/uint8이며 물리적 광도 합성·gamma 보정은 아니다. B-032에서 재사용한 것은 이 blend와 끝값을 명시적으로 원 byte로 복사하는 불변성 원리다. 옛 차량 mask·normalized raw·해상도·fps는 가져오지 않았다.

B의 provenance는 실제 시작/끝 앵커다. 각 앵커의 공 중심52px 안은 보이지 않는 배경으로 취급한다. 공통으로 보이는82,846픽셀은 exact이고 두 관측의 합집합이 화면 전체를 덮었다. 시작 우선 복사로91,343픽셀과 끝8,497픽셀을 얻었으며 unknown0이다. unknown은 두 입력 모두 배경을 보여 주지 못한 영역이며 상상이나 정답 renderer로 채워서는 안 된다. 이번 toy에서는 unknown이 없을 뿐 실제 장면도 그렇다는 뜻은 아니다.

alpha는 정답 객체 분할이 아니라 알려진 크기·경로에 여유를 둔 편집 영역이다. RAW 객체가 늘어나거나 잔상이52px 밖까지 퍼지면 일부를 지울 수 있다. 따라서 core exact와 전체 객체 보존은 동치가 아니다. 늘어진 synthetic fixture는 exact 검사를 통과해도 일부가 잘릴 수 있음을 보여 준다. 실제 세 사례에서는 검토한 시트/crop 범위에 뚜렷한 공 잘림이 없었으나 완벽한 support segmentation은 얻지 않았다.

복사 outside의 MAE0은 C=B를 직접 강제한 결과다. 이를 독립적인 성능 점수로 삼지 않고 위치·단일 판독·잘림·경계를 함께 본다. 이번 전33프레임 중심은RAW/POST 모두 같았다. I50/S는 배경 얼룩 제거가 있고 큰 새 경계 손상은 보이지 않았지만 공 내부 손상은 그대로다. seed2는 전역 붕괴가 사라져도 collar MAE18.510과 원형 모자이크가 남아 boundary tradeoff다.

무손실 PNG의 exact는 저장/readback 후 실제 byte로 확인했다. MP4는 libx264 손실 미리보기이므로 exact를 주장하지 않는다. RAW MP4는 원 파일 그대로 전달했고 POST만 새로 인코딩했다.33/16초 파일 길이와 양끝 샘플 간32/16초는 다르다.

경로·외형·장면·경계·시간을 분리해야 한다. 배경이 정적이어도 움직이는 alpha가 국소 오염을 드러내거나 감추며 popping을 만들 수 있다. 전33정적 시트·브라우저 재생·ffmpeg 성공은 연속 지각 검수가 아니므로 temporal=UNVERIFIED다.

실사용에서는 배경 미관측,가림,그림자,카메라 이동,노출 차이가 추가된다. 이번에는 exact한 정적 공통 관측과 알려진 크기/경로가 있는 toy다. 정합·inpaint·분할·warp나 모델 추론을 수행하지 않았다.

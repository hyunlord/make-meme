# C-010 해설 — "신호가 들어간다"와 "쓸모 있게 쓰인다"는 다르다

## 1. 표면점·관절·가시성
track ID는 한 영상 안의 **표면점** 번호이며, 부위의 의미가 아니다. elephant의 #6처럼 몸 밖(물줄기·지면)에 놓인 점도 있다.
`visible`은 tracker 출력이고, `make_null`은 양끝이 보이면 중간을 모두 visible로 둔다. 그래서 ON/NULL 차이에는 위치뿐 아니라 **가시성 비트**도 섞여 있다. 실제로 NULL에서만 gate인 점이 93–343개였다.

## 2. 입력이 다름 · 모델이 반응함 · 정답으로 좋아짐
세 질문은 따로 확인해야 한다.
- 입력은 3.7–24 px만큼 달랐다.
- 모델은 반응했다: 예측의 1–2%.
- 그런데 그 반응은 정답 오차를 줄이는 방향이 아니었다. 이번 진단의 핵심이 이 세 번째 단계다.

## 3. FP32 residual → BF16 cast → 실제 덧셈
`residual()`은 `hidden + update.to(bf16)`이다. BF16의 상대 분해능은 약 2⁻⁸ ≈ 0.4%다. residual이 hidden의 2.5% 정도라 원소 단위로는 16–29%가 반올림에 먹혔다.
하지만 남은 원소가 크므로 RMS 기준 실효/의도 비는 1.00이었다. **원소 수와 에너지는 다른 척도**다.

## 4. 시간 평균의 에너지 감소 η
`η = sqrt( Σ_g |g|·||mean_{t∈g} d_t||² / Σ_t ||d_t||² )`.
같은 group 안에서 프레임 차이가 서로 반대면 평균에서 상쇄되어 η가 작아진다. 이번에는 η = 0.96–0.98로 거의 보존됐다.
η가 작았더라도 그것은 "에너지가 줄었다"는 뜻일 뿐, 의미 있는 움직임이 사라졌다는 증명은 아니다.

## 5. 손실 차이의 분해
balanced loss의 가중 내적: `⟨a,b⟩_W = Σ M·mean_c(ab)/ΣM + Σ(1−M)·mean_c(ab)/Σ(1−M)`.
`e_B = u* − v_B`, `Δ = v_A − v_B`이면

    L_A − L_B = ||Δ||²_W − 2⟨Δ, e_B⟩_W

- Δ가 오차 방향(cos > 0)이고 충분히 크면 손실이 준다.
- 방향이 직교(cos ≈ 0)면 ||Δ||²만큼 **늘어난다**.

이번 결과는 이렇다:
- ON−BASE는 높은 σ에서 cos 0.14–0.25로 손실을 줄였다. 하지만 NULL−BASE도 똑같이 줄였으므로 공통 보정이다.
- ON−NULL은 cos −0.06 ~ +0.02로 손실을 늘렸다.

수치 확인: 직접 계산한 차이와 분해식의 오차는 ≤ 2e-16이었다.

## 6. parameter gradient · 입력 Jacobian · 유한 차분
- `positions.detach()` 때문에 좌표에 대한 gradient는 None이다. 그래도 adapter parameter는 좌표가 만든 feature와 Gaussian 가중치를 통해 학습된다. **입력 detach는 학습 단절이 아니다.**
- parameter gradient의 ON/NULL cos가 0.95 이상이라는 것은 이런 뜻이다: 같은 noisy state에서 궤적을 바꿔도 "어디로 고치라"는 신호가 거의 같다. 학습이 궤적을 구별할 이유를 받지 못했다.
- 유한 차분은 실제 함수의 반응을 잰다. context는 변위에 비례해 변했지만, 예측 변화는 비례하지 않았다. 4px와 8px의 예측 변화가 같은 크기였고 방향 cos는 0.05–0.17이었다. 국소 선형 민감도라고 부를 수 없는 반응이다.

## 7. 서로 다른 단위의 norm 비교 금지
`delta_q` 열의 gradient는 원소당 1e-7, patch 열은 1e-5다. 하지만 delta_q 입력 자체가 0.002–0.01 크기이고 2차원뿐이다. "외형 patch가 지배한다"거나 "delta_q가 무시된다"를 이 숫자만으로 결론내리지 않는다.
경계를 넘는 원시 norm의 비교도 하지 않았다. 사슬 그래프의 각 점은 그 경계 안의 상대 차이일 뿐이다.

## 8. one-step과 실제 생성
probe의 z_σ는 정답 z0에서 만든 상태라서 중간 동작 정보를 이미 품고 있다. 생성 중의 상태는 그렇지 않다.
저장된 C-009 rollout 상태에서도 ON−NULL 크기는 BASE의 0.5–1.7%로 비슷했다. 다만 정답 velocity가 없어 방향은 판단할 수 없다. 영상 품질 판단(temporal=UNVERIFIED)은 바뀌지 않는다.

## 9. 현재 hidden을 보지 않는 adapter
adapter MLP의 입력은 점 정보와 σ뿐이고, 현재 hidden(지금 장면 상태)은 보지 않는다. 그래서 같은 점 조건이면 상태와 무관하게 같은 residual을 더한다.
이것이 보정 방향이 틀어진 이유일 **수 있다**. 하지만 이번 증거로는 조건 중복 설명보다 우선한다고 볼 수 없어 단정하지 않는다.

## 10. 확인한 것 / 못한 것
- **확인**: 신호가 adapter·주입·예측까지 전달된다(shape [33,K,303] → [1,3510,192] → [1,3510,1536] → [1,16,9,30,52]). 관측 사본은 원본과 bit-exact였다. ON−NULL 변화의 방향과 gradient 유사성을 확인했다.
- **못함**: 동적 윤곽 제거 대조(다음 의뢰), 영상 품질과의 연결, 정답 관절·접촉 평가, 섭동 바닥의 정식 측정(임의 섭동 대조).

## 이해 확인
- Q: residual이 hidden의 2.5%뿐이니 키우면 되나? A: 아니다. 지금도 예측은 바뀌고 있고, 바뀐 방향이 틀렸다. 크기를 키우면 ||Δ||² 항이 커져 손실이 더 늘 수 있다.
- Q: NULL과 ON의 gradient가 거의 같다는 것은 무슨 뜻인가? A: 학습 신호 입장에서 궤적이 있든 없든 할 일이 같았다는 뜻이다. 궤적을 쓰게 만드는 압력이 없었다.

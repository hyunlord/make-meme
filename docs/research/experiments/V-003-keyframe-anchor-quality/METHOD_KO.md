# V-003 방법과 관측 범위

V-002 M1은 사용자가 네 발 자세로 무너지고 춤이 사라졌다고 판정했다. 마스크는 편집할 영역을 알려 주지만 같은 세로 덩어리가 직립한 몸인지 정면의 네 발 몸인지 충분히 구분하지 못할 수 있다. 회색 내부에는 다리 배치가 없다. 이것은 가능한 원인 설명이며 이번 비교만으로 원인을 분리해 입증하지는 않는다. V-003 앵커에는 관측한 순간의 실제 RGB 자세를 넣고, 여러 시점에 같은 외형과 자세를 안내한다.

고정 LTX 코드에서 replace는 인과적 VAE latent 시작 위치에 대응하는 조건을 사용한다. 첫 프레임 또는 1+8k 위치 제약 때문에 K3의 요청 위치와 가장 가까운 실제 앵커 시점이 다를 수 있으며 오프셋을 보존한다. guide는 임의 시점의 키프레임 안내 조건을 추가한다. 두 방식 모두 같은 공식 two-stage 경로에서 이미지 조건을 구성하며, 내부 latent 조건을 출력 RGB의 완전한 byte 고정으로 해석하지 않는다. 실제 코드 근거는 RUNTIME_LTX.md에 둔다.

이 흰 배경 장면에서 canny는 다리와 몸의 이미지 경계를 제공하고 depth는 표면 거리 정보를 제공한다. 낮은 depth 대비보다 canny 경계가 자세에 도움이 될 것이라는 가설을 K1과 K2로 비교한다. canny도 원본 체형의 경계를 담아 더 큰 래브라도와 충돌할 수 있다. 자동 IoU·bbox 비율·임베딩은 참고값이고 동작 성공이나 Kling 대비 우열의 판정기가 아니다.

RAW는 모델 원출력으로 보존한다. POST는 원본과 출력의 SAM 개체·반사를 합친 영역 안에 생성 픽셀을 남기고, 설정된 팽창·feather 후 밖을 원본으로 복사한 CPU 파생본이다. 이 합성은 배경을 보존할 수 있지만 잘못된 다리·털·시간 동작을 교정하지 않는다. 항상 RAW와 POST를 함께 제공하고 품질은 HUMAN_REVIEW_PENDING으로 둔다.

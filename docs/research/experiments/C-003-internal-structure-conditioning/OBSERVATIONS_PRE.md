## 재개 입력 검토 — 출력 생성 전

실제 J/DYNAMIC/HOLD 전체33장과 source/J/I/양조건 고정9장, full-resolution D8/D16/H16/I16을 정적으로 확인했다. DYNAMIC에는 시점별 눈/코/귀·주둥이의 선과 일부 앞다리 안쪽 경계가 있고 배경선은 I밖에서 제거됐다. HOLD는 첫 얼굴무늬가 현재 bbox를 따라 좁아지면서 화면 오른쪽으로 치우치거나 잘린다. 이는 bbox-only가 의미적 얼굴 대응이 아니라는 대조군의 한계이며 좌표 오류로 고치거나 튜닝하지 않는다. 몸통·발 안쪽은 희박하고 얇은 부위는 제외되므로 관절·접촉을 충분히 표현했다고 하지 않는다. K0/32는 진단이며 실제 X0/32는 원래 앵커로 검증한다.

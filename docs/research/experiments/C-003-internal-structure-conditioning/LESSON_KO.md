# 외곽선 안의 시간 정보 — 구현과 실제 두 출력의 한계

## 직관: 같은 외곽선에도 다른 자세가 가능하다

실루엣은 객체가 차지하는 영역을 말하지만, 가려진 앞다리가 어디에 있는지나 고개가 몸 앞에서 어떻게 돌아가는지를 유일하게 정하지 못한다. 서로 다른 내부 자세 q₁,q₂도 비슷한 silhouette을 만들 수 있다. C-002 개의 접근은 거칠게 개선됐지만 내부 발 진행은 불확실했다. C-003은 그 부족한 정보를 구조선으로 더할 때 도움이 되는지 묻는다. 최초 가드 중단은 보존했고, 별도 승인 재개 뒤 실제 입력과 두 출력을 비교한다.

## 수식: 이동·크기와 내부 변화 구분

bbox 중심 c_t, 폭·높이 D_t=diag(w_t,h_t)에 대해 p=c_t+D_tu다. u는 객체 bbox 안의 정규화 좌표다. 이 식은 이동과 축척을 맞출 뿐 회전, 비강체 관절, 앞뒤 대응을 알아내지 않는다.

S_t는 SAM 영역, L_t는 흰 바탕 검정 외곽선, J_t는 구조 추출기의 grayscale, I_t는 내부거리>4px이면서 L이 흰 영역, G_t는 VACE 생성 여부 마스크다. S나I를 G로 사용하지 않는다.

선 강도 d_t=I_t(1−J_t/255)를 bbox의256×256에 bilinear로 샘플링한다. DYNAMIC은 각 시점 d_t^N을 현재 bbox로 돌려놓고, HOLD는 첫 d_0^N을 현재 bbox로 돌려놓는다. 둘 다 현재 I_t로 clip한다. 따라서 HOLD도 이동·크기·실루엣 clipping에 따라 변하며 완전한 motion-off가 아니다. `prepare_internal.normalize/restore/composite`가 이 경로를 구현하고 CPU 테스트가 좌표·경계 불변성을 확인한다. 실제33장에서도 I밖동일·DYNAMIC/HOLD차이·배경선제거를 확인했다.

I 밖은 L 그대로이며 안은 round(255(1−D))의 회색을3채널로 반복한다. 양끝은 원래 앵커, 중간만 이 K다. 원본 RGB 색은 넣지 않지만 털 경계·질감·가림·체형 단서가 구조선에 남을 수 있다. identity-free 표현이 아니다.

## 텐서: 내부 정보가 들어갈 자리

기존 DiffSynth 경로의 X는 RGB×2/255−1이다. U=Encoder((1−G)X), R=Encoder(GX)에서 양끝 앵커는 inactive U, 중간 구조는 reactive R에 들어간다. normalized0은 uint8검정0이 아니다. U16채널+R16채널+mask64채널이 context96이 된다. 이 연결은 부모 코드에서 확인됐고 C003은 그대로 재사용하도록 구현했다. 실제첫model_fn의 context/noise/mask64 관측은 NUMERICS에 기록한다. Hash차이는 전달의 증거이지 유용성의 증거가 아니다.

영상 시간 t의33개 표본은 VAE에서9개 시간 latent로 압축된다. 생성 진행도 s의50 Euler step은 잡음을 영상으로 바꾸는 반복이며50프레임이 아니다. 기존 nearest-exact33→9 mask에서 endpoint의0이 빠지는 한계는 유지한다. RGB 앵커의 U조건이 남는 것과 mask채널이 모두1이 되는 현상은 다르다.

## 관측과 반례·한계

실제 두 출력은 생성에 성공했지만 DYNAMIC의 머리·다리 진행이 OUTLINE_ONLY와 HOLD보다 명확하게 좋아졌다는 증거는 없다. 검정/흰 외형은 남고 코·얼굴 세부가 달라지지만, 보이는 앞발의 거친 배치 패턴은 세 조건에서 비슷하다. 낮은 머리와 종료 앵커의 웅크림 충돌도 남는다. 배경 풀·울타리 질감 변형은 일부 더 두드러진다. 따라서 조건 전달 PASS와 NO_ESTABLISHED_GAIN을 함께 기록한다.

조건이 늘면 p(Y|A₀,A₃₂,P,L) 대신 p(Y|A₀,A₃₂,P,L,J)를 겨냥하지만 품질의 단조 개선은 보장되지 않는다. 실제 J는 눈·코·귀 일부를 표현하지만 몸통·얇은 발의 내부 선이 드물다. HOLD의 초기 얼굴 패턴은 현재 bbox에 따라 옆으로 밀리고 clip된다. 선 밀도·가림·질감 누수·앵커 충돌·미검증 혼합 표현 중 단일 원인을 확정할 수 없다.

정보 부족과 모델의 조건 미활용은 이번 한 사례/seed로 분리되지 않는다. 다음 후보 하나는 **가시성·신뢰도를 포함한 시간별 객체 내부 대응**이다. 의미 있는 부위를 선택적으로 연결할 필요성의 후보이며, 점 추적기·학습·새 생성은 이번에 수행하지 않는다. 구조선 proxy의 이득 미입증을 내부 대응 연구 전체의 실패로 확대하지 않는다. 연속 지각 검수가 없어 temporal=UNVERIFIED다.

## 이해 확인

1. HOLD는 완전히 정적인 조건인가? **정적이지 않다.** 첫 내부 무늬만 고정되고 현재 bbox와I에 따라 이동·확대·잘림이 바뀐다.
2. 검은 구조선이 생성 마스크의0인가? **아니다.** 구조선은 RGB조건이고 G는 별도의 whole-frame mask다.
3. CPU 좌표 검사가 PASS면 내부 동작 이득인가? **아니다.** 실제 조건 전달과 생성 결과 비교가 필요하다. 이번에는 전달을 확인했지만 품질 이득은 미입증이다.
4. 가드 중단이 구조선 방법 실패를 뜻하는가? **아니다.** 초기 실행은 전달 전에 중단됐고 기록을 보존했다. 이후 명시적 amendment 승인으로 두 실제 출력을 얻었다.

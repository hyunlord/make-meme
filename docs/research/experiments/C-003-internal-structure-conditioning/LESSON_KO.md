# 외곽선 안의 시간 정보 — 구현과 아직 없는 실험 결과

## 직관: 같은 외곽선에도 다른 자세가 가능하다

실루엣은 객체가 차지하는 영역을 말하지만, 가려진 앞다리가 어디에 있는지나 고개가 몸 앞에서 어떻게 돌아가는지를 유일하게 정하지 못한다. 서로 다른 내부 자세 q₁,q₂도 비슷한 silhouette을 만들 수 있다. C-002 개의 접근은 거칠게 개선됐지만 내부 발 진행은 불확실했다. C-003은 그 부족한 정보를 구조선으로 더할 때 도움이 되는지 묻는다. **이번에는 가드 중단으로 실제 답을 얻지 못했다.**

## 수식: 이동·크기와 내부 변화 구분

bbox 중심 c_t, 폭·높이 D_t=diag(w_t,h_t)에 대해 p=c_t+D_tu다. u는 객체 bbox 안의 정규화 좌표다. 이 식은 이동과 축척을 맞출 뿐 회전, 비강체 관절, 앞뒤 대응을 알아내지 않는다.

S_t는 SAM 영역, L_t는 흰 바탕 검정 외곽선, J_t는 구조 추출기의 grayscale, I_t는 내부거리>4px이면서 L이 흰 영역, G_t는 VACE 생성 여부 마스크다. S나I를 G로 사용하지 않는다.

선 강도 d_t=I_t(1−J_t/255)를 bbox의256×256에 bilinear로 샘플링한다. DYNAMIC은 각 시점 d_t^N을 현재 bbox로 돌려놓고, HOLD는 첫 d_0^N을 현재 bbox로 돌려놓는다. 둘 다 현재 I_t로 clip한다. 따라서 HOLD도 이동·크기·실루엣 clipping에 따라 변하며 완전한 motion-off가 아니다. `prepare_internal.normalize/restore/composite`가 이 경로를 구현하고 CPU 테스트가 좌표·경계 불변성을 확인한다. 실제 source 구조선을 넣은 검증은 미실행이다.

I 밖은 L 그대로이며 안은 round(255(1−D))의 회색을3채널로 반복한다. 양끝은 원래 앵커, 중간만 이 K다. 원본 RGB 색은 넣지 않지만 털 경계·질감·가림·체형 단서가 구조선에 남을 수 있다. identity-free 표현이 아니다.

## 텐서: 내부 정보가 들어갈 자리

기존 DiffSynth 경로의 X는 RGB×2/255−1이다. U=Encoder((1−G)X), R=Encoder(GX)에서 양끝 앵커는 inactive U, 중간 구조는 reactive R에 들어간다. normalized0은 uint8검정0이 아니다. U16채널+R16채널+mask64채널이 context96이 된다. 이 연결은 부모 코드에서 확인됐고 C003은 그대로 재사용하도록 구현했다. 이번 새로운 context는 실제 생성되지 않았다.

영상 시간 t의33개 표본은 VAE에서9개 시간 latent로 압축된다. 생성 진행도 s의50 Euler step은 잡음을 영상으로 바꾸는 반복이며50프레임이 아니다. 기존 nearest-exact33→9 mask에서 endpoint의0이 빠지는 한계는 유지한다. RGB 앵커의 U조건이 남는 것과 mask채널이 모두1이 되는 현상은 다르다.

## 관측과 반례·한계

실제 관측은 source·기존 앵커·C002와 시작 가드까지다. 새 DYNAMIC/HOLD가 없으므로 내부 진행·외형·배경 이득이나 손해를 주장할 수 없다. 조건이 늘면 p(Y|A₀,A₃₂,P,L) 대신 p(Y|A₀,A₃₂,P,L,J)를 겨냥하지만 원하는 품질의 단조 개선은 보장되지 않는다. source 외형 누수, 앵커 충돌, 선 밀도 차이, pretrained 모델에 낯선 혼합 표현이 반례 후보다. 이들은 아직 관측된 원인이 아니다.

정보 부족과 모델의 미활용을 구분하려면 유효한 실제 조건과 출력이 필요하다. 이번 안전 중단은 둘 중 어느 쪽도 검증하지 않는다. 시간별 의미 대응·가시성/confidence·target retargeting은 구현하지 않았다. 다음 개입은 이번 보류 사실과 기존 결과를 검토한 뒤 정한다.

## 이해 확인

1. HOLD는 완전히 정적인 조건인가? **정적이지 않다.** 첫 내부 무늬만 고정되고 현재 bbox와I에 따라 이동·확대·잘림이 바뀐다.
2. 검은 구조선이 생성 마스크의0인가? **아니다.** 구조선은 RGB조건이고 G는 별도의 whole-frame mask다.
3. CPU 좌표 검사가 PASS면 내부 동작 이득인가? **아니다.** 실제 조건 전달과 생성 결과 비교가 필요하다. 이번에는 모두 미실행이다.
4. 가드 중단이 구조선 방법 실패를 뜻하는가? **아니다.** 모델에 조건을 전달하기 전에 중단됐다.

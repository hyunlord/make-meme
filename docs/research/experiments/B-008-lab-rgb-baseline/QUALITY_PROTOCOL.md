# B-008 사전 품질 검토 표

기준: PLAN §5. 결과를 본 뒤 좋은 프레임만 고르지 않고 전체 f0~16을 확인한다. 고정 확대 검토 프레임은 f0/4/8/12/16이며 동일 화면 좌표와 크기를 유지한다. 영상은17프레임·24fps·0.708333초다. loop 끝→처음 전환은 내부 불연속으로 채점하지 않는다.

| 평가 축 | 근거 | 사전 상태 |
|---|---|---|
| 검은 Labrador 견종 외형 | 참조와 전체 출력의 귀·주둥이·털 | NOT_RUN |
| 실제 반려견 개체 | 실제 참조 얼굴/체형과 비교; 견종 유사성만으로 통과 금지 | NOT_RUN |
| 체형 | 넓은 가슴·몸통·굵은 사지, source의 가는 체형 누수 | NOT_RUN |
| 직립 자세 | source와 동시점 출력; reference 착석 고정 여부 | NOT_RUN |

| source/reference 외형·자세 누수 | source 얼굴·몸통·배경과 참조 착석을 별도 관찰 | NOT_RUN |
| 형상·mask | 머리·목·사지·꼬리, 경계/반사/접촉; 불가시 부위는 추정하지 않음 | NOT_RUN |
| 프레임 간 외형 변화 | 전체 시트 정적 비교로 확인 가능한 범위 | NOT_RUN |
| 실제 속도의 시간 품질 | 관찰 주체와 실제 연속 재생 여부 기록 | UNVERIFIED |

결과별 PASS/FAIL/UNCERTAIN와 근거 프레임을 적는다. 전체 점수·성공률·PSNR 정답을 만들지 않는다. mask의 기존 얇은 발·꼬리·바닥 결함은 PARTIAL_UNRESOLVED이며 결과를 본 뒤 mask를 수정하지 않는다. 출력에 업스케일·보간·복원·warp를 적용하지 않는다. 파일 decode 성공은 사람의 재생 품질 검토가 아니다.

이번에는 VACE와 다른 조건을 섞은 우월성 비교를 하지 않고 해당 baseline 한 건을 해석한다. 관측된 실패를 근거로 다음 실험 하나만 제안한다.

# V-004 방법과 해석

원본 canny의 작은 개 윤곽과 앵커의 큰 래브라도가 요구하는 크기를 맞추기 위해, 수용 앵커의 bbox 높이비 중앙값을 개체별 고정 배율로 사용한다. 몸은 원본 bbox 아래쪽 가운데, 반사는 위쪽 가운데를 기준으로 확대해 접지 위치를 유지한다. 원본 다리의 방향과 시간 순서를 가진 윤곽을 더 큰 공간에 제공하려는 방법이다. 배율을 프레임마다 바꾸거나 생성 결과를 보고 조정하지 않는다.

다만 **얇은 개를 균일하게 확대한 윤곽은 래브라도의 넓은 가슴·굵은 다리·머리 형태가 아니다.** 크기 충돌을 줄일 수 있어도 체형과 자세가 완전히 맞는다는 보장은 없다. 앵커와 확대 마스크의 IoU, 겹침·화면 밖 잘림을 기록하는 이유다. 최상단 마스크 점도 발끝 대신 귀나 머리일 수 있으므로 방향 지표는 참고값이며 자동 우열 판정에 쓰지 않는다.

LTX의 시간 압축은 8배다. 73프레임은 latent 시간칸 10개, 145프레임은 19개가 된다. S3는 모델의 압축률을 바꾸지 않고 원본 시간축을 두 배로 늘린다. 조건은 `floor(i/2)`번째 원본 윤곽을 쓰며, 앵커 k는 생성 위치 2k에 둔다. 145칸 중 원본 0–71은 두 번씩, 마지막 72는 한 번 들어간다. 같은 원본 동작을 더 많은 생성 시간칸에 배치하려는 비교다.

S3 원출력 145프레임을 보존하고 짝수 프레임 0, 2, …, 144를 골라 73프레임·24fps 비교본을 만든다. 이는 CPU 프레임 선택 파생본이며 보간으로 새 프레임을 만드는 처리가 아니다. 입력 윤곽을 반복했다고 중간 자세 정보가 새로 생기지는 않고, 선택 후 끊김·잔상이 커질 수도 있다. 촘촘한 앵커만 바꾼 S1, 확대 윤곽을 더한 S2, 시간축까지 늘린 S3를 실제 발차기 구간으로 비교해야 한다. 여섯 생성과 SAM·CPU·참고 embedding 측정은 완료했지만 이 수치만으로 효과를 확정하지 않으며 품질은 HUMAN_REVIEW_PENDING이다.

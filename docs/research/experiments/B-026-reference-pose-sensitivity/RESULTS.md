## 확인한 범위와 관측

기존 연구 manifest와 허용된 사용자 원본 사진 묶음만 확인했다. 원본 11장(JPEG 9장, HEIC 2장)을 직접 정적 검토했으며, HEIC는 기존 OS 도구로 열람용 PNG를 만들었다. 새 모델·패키지는 설치하지 않았다. 개인 홈 전체나 외부 이미지를 검색하지 않았다.

| 자료 | 실제 관측 | 이번 입력 판정 |
|---|---|---|
| 기존 IG 참조 및 다른 침대·쿠션 사진 | 누움·웅크림·기대어 쉬는 자세 | 확정된 standing reference가 아님 |
| 차량 내 IG 사진(원본 묶음 008) | 머리·가슴을 세우고 앞다리를 편 모습. 캐리어 메시·테두리·좌석·뒤의 다른 개체 때문에 몸통 후반과 뒷다리 지지 상태가 불명확 | PARTIAL_UPRIGHT / FOUR_LEG_SUPPORT_UNCERTAIN |
| 나머지 Lab 사진 | 대상 IG의 기립 참조가 아님 | 제외 |
| 등록된 원본 영상 계보 | 같은 IG의 기립 프레임을 제공하는 원본 영상은 확인되지 않음. 다른 source 개체 영상과 생성물은 대체 자료로 쓰지 않음 | 적합 후보 0 |

차량 사진을 제외한 이유는 네 발이 모두 선명해야 한다는 추가 조건이 아니다. 이번 독립 입력 조건인 자연스러운 사족 기립 자체를 확인하기 어렵고, 강한 가림이 함께 들어가기 때문이다. 같은 개체 여부는 기존 사용자 제공 계보와 구분해 다루며 견종·시각적 유사성만으로 확정하지 않았다. 에이전트의 정적 관측은 독립 인간 정답 주석이 아니다.

이 결과는 확인한 허용 자료 안에서의 결론이다. 다른 곳에도 사진이 없다는 뜻은 아니다. 필요한 자료는 **같은 IG가 자연스럽게 네 발로 서 있는 실제 원본 사진 한 장**(또는 개체 계보가 확인된 기존 원본 영상의 해당 프레임)이며, 머리·몸통·주요 사지가 관측 가능해야 한다. 기존 자료의 사용 권한을 다시 요청하지 않는다.

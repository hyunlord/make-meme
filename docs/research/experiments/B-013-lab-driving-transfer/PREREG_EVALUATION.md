# B-013 사전 평가 — B-012 사건 유지

신규 P/생성 전 고정. 입력은 원본source[7,24), local0~16, 동일512×896·24fps다. source-only 재선정·좌표 재주석·crop/mask 수정은 없다. B-012 전체17장과 아래 사전 사건을 그대로 사용한다.

| local/source | 원본 사건 |
|---|---|
| 0/7 | 약한 머리 기울임, 전면 몸통, 주둥이 아래의 굽힌 앞발 |
| 12/19 | 끝보다 작은 head roll, 전면 몸통, 앞발이 몸 앞에 유지 |
| 14/21 | 몸통 방향보다 머리 roll이 더 증가하는 후반 단계 |
| 16/23 | 가파른 눈 연결선의 큰 head roll, 전면으로 기운 몸통, 보이는 양 뒷발 |

주 비교는 LAB_MOV 대 LAB_STILL이다. 기존 source MOV/STILL은 B-012 원본 결과를 재사용한 맥락 비교이며 새 생성하지 않는다. 원본/source와 Lab 행은 reference 자세·체형·장면·text가 달라질 수 있어 순수identity효과나 통계적interaction으로 해석하지 않는다.

1. **A 전신 자세:** 뒷발 직립과 굽혀 든 앞발이라는 source 배치가 재현되는지, Lab reference의 착석/바닥을 짚은 앞발이 유지되는지 구분한다. 머리만 움직였다는 이유로 A를 PASS하지 않는다.
2. **B 국소 동작:** 후반 머리 roll의 source 방향·증가 순서·같은 표본 시점 대응이 LAB_MOV에서 LAB_STILL보다 관측되는지 본다. 전체 영상의 이동·scale·회전과 몸통에 대한 머리 변화는 분리한다. 앉은 채 머리만 대응하면 A실패/B부분근거를 함께 기록한다.
3. **C 정체성·체형:** 검은 Lab 견종 유사성과 실제 사진 개체 일치는 별도다. 얼굴·귀·주둥이·넓은 가슴·굵은 사지, source 옅은 털·가는 몸 누수, 회전 중 얼굴 변형을 기록한다. 검은 색만으로 실제개체PASS를 주지 않는다.
4. **세부·시간:** 전체17장coverage·형상·가림·앞발·반사·경계를 모두 남긴다. 불명확한점은UNCERTAIN, 숨은관절/3D접촉UNKNOWN. 정확한각도·오차보정 없는gain·유의성은 계산하지 않는다. 직접연속시각검수 없으면temporalUNVERIFIED.

가능하면 A/B 라벨로 가린 동일 canvas 패널에서 먼저 관찰하고 대응표를 나중에 연다. 이는 라벨노출을 줄이는 절차일 뿐, 동일 source를 아는 agent의 검토를 독립인간blind ground truth로 부르지 않는다. 미용후처리·warp·정합/시간축탐색·보간·업스케일·좋은프레임선별은 없다.

조건4변경/12보존·대응B-0127변경/9보존·코드/입력무결성은 실행통제판정이다. 가드/latent/readback/MP4 성공도 영상품질 수용과 별도다. 첫 출력의 품질실패는 안전한STILL실행을 생략할 이유가 아니다.

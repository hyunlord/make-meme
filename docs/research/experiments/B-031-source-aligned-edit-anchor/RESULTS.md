# B-031 결과: 생성 앵커와 영상 전이를 분리한 기준선

최종 상태: COMPLETED / 기술 실행 PASS / 결합 편집 목표 FAIL. 일반 기준선으로 채택하지 않는다. B-030 PARTIAL/INCONCLUSIVE 및 B-028/B-029 NOT_ADOPTED는 그대로 보존한다.

## 앵커에서 원하는 대상과 원본 자세를 함께 만들었는가?

차량에서는 정적 근거가 있었지만, 동물·사람 R1에서는 실패했다. Qwen의 실제 이미지 6회는 모두 기술적으로 완료됐으나 이것을 앵커 적합성 6회 성공으로 바꾸어 쓰지 않는다. [전체 6개 판정](ANCHORS.md).

| 과제 | R1의 실제 관측 | 사전에 정한 영상 선택 |
|---|---|---|
| 동물 | 검은 장모 외형은 반영됐지만 낮게 누운/웅크린 참조 자세가 남고, 원본의 들린 몸통·꼬리·걷는 앞발 배치가 사라짐 | ANCHOR_UNSUITABLE, 영상 NOT_RUN |
| 사람 | 흰 블라우스·분홍 치마·땋은 머리는 반영됐지만 원본의 정면/머리 뒤 팔/교차한 발 대신 참조의 뒤·옆모습과 펼친 치마를 따름 | ANCHOR_UNSUITABLE, 영상 NOT_RUN |
| 차량 | 높은 은색 차체·창·루프레일·세로 후미등을 반영하고, 반대 방향의 참조를 그대로 복사하지 않고 원본처럼 오른쪽을 향함 | SUITABLE_FOR_VIDEO, R1 한 건 진행 |

동물 R2와 사람 R2는 R1보다 일부 원본 자세에 가까웠지만 머리·팔·발 또는 치마 배치의 차이가 남았다. 차량 R2도 대상 외형과 원본 방향을 대체로 반영했다. 세 R2 모두 실제 결과를 보존하되 사후 영상 후보로 대체하지 않았다.

정적 판독은 실제 source/target/A0를 연 parent와 별도 agent의 관측이다. 일부 요약을 공유했으므로 blind 검토가 아니며, 인간 독립 ground truth나 개인 신원 인증도 아니다. 대상의 구분 가능한 옷·털·차체 특징과 실제 instance의 완전한 일치는 구분한다.

## 영상으로 이어졌는가?

차량 R1만 새로 만든 실제 A0 support로 R_star를 구성했다. 수동 작업은228.29초였고, 안쪽 RGB exact equality·바깥128·RED/BLACK 마스크·기록된 polygon의 CPU 재현을 확인했다. 원본 차체 마스크를 그대로 씌우지 않았고 도로 그림자는 제외했다. 얇은 루프레일·spoiler·타이어 경계의 약1~3px 불확실성은 남는다.

Qwen worker의 실제 종료와 메모리 회복 뒤 차량 ENC→PROBE→S→D를 순차 완료했다. 부모는 B-027 vehicle R1이며 양 CFG 참조 VAE/CLIP/mask의6leaf만 바꾸고 나머지10leaf와 초기 noise·RNG·scheduler를 보존한다. A0를 출력 첫 프레임으로 붙이거나 clamp하지 않는다. 실제40step·80forward, finite final latent [16,5,64,112]와 decoded [3,17,512,896], 17프레임 MP4를 확인했다.

전체17장 및 local0/8/16 정적 관측에서 높은 은색 차체·창·루프레일·세로 후미등은 유지되고, 원본의 오른쪽 이동과 후면 노출 증가에 대략 대응했다. B027 R1보다 target형 차체의 정적 근거가 있으나 정확한 개체·접촉·동작 타이밍은 UNCERTAIN이다. **좌하단 도로에는 A0와 원본에 없던 큰 적색/흰색/검정 차량 부품형 그래픽이 전체17장에 지속됐다. 보호 장면은 FAIL이다.** B027 R1에도 별도 그래픽이 있었으므로 이 문제를 해결하지 못했다. 외형 PARTIAL·거친 움직임 PARTIAL을 결합 목표 PASS로 합치지 않는다. 이는 적합했던 차량 앵커 이후 영상 전파 단계의 실패이며 특정 encoder 원인은 확정하지 않는다.

## 기술 실행과 해석 한계

- Qwen:6/6 호출 완료, 각40step·80forward, finite512×896×3 raw와 decode 전 packed latent 저장. 이미지 모델/환경 고정 후 로컬 파일만 사용했다.
- 새 모델은 Qwen 한 종이며 새 패키지 설치·학습·imagegen·외부 생성·자동 재시도는0이다. 기존 SCAIL과 서비스 환경을 변경하지 않았다.
- 정적 앵커의 실패와 SCAIL 전파 단계의 실패를 분리한다. 아직 실행하지 않은 과제를 영상 실패로 세지 않는다.
- 공개 개발 패널3과제×2참조다. 6개 출력이나 여러 프레임을 독립 반복으로 세어 일반 성공률·논문 성능을 주장하지 않는다.
- 원본 FPS가 확인되지 않아 `source_fps=null`, `preview_fps=24`, `timebase_assumed=true`를 유지한다. 연속 시청 근거가 없으므로 영상 temporal=UNVERIFIED다.
- raw 출력의 ROI 합성·얼굴 복원·SR·보간·warp·문자 제거를 하지 않는다. 원본 장면의 큰 배치가 비슷해도 세부 보호영역을 픽셀 단위로 보존했다고 하지 않는다.

## 비용과 산출물

Qwen worker43.315분,6개 pipeline 호출 합38.405분, CUDA peak allocated55.933GiB, 최소 관측 MemAvailable25.935GiB다. 다운로드 정체와 transport fallback, 실제 프로세스 종료 전 잔존 allocation도 [COSTS](COSTS.md)에 포함했다. 모델 파일 크기·CUDA·RSS·cgroup 회계는 합산하지 않는다.

원본/두 target/B027/A0/R_star/실제 생성 영상은 비공개 viewer에 모은다. 모든 앵커와 생략 사유를 유지한다. full은 raw/latent·효과적 encoder 입력을, compact는 실제 제공 입력·앵커·영상·보고서와 full 전용 파일의 해시 명세를 포함한다. MP4는 재인코딩하지 않는다. 최종 ZIP 검증과 실제 경로는 DELIVERY에서 별도로 보고한다.

다음 한 가설: 적합한 앵커가 있어도 영상 생성 과정의 보호 영역 조건이 충분하지 않아 새 도로 그래픽이 생길 수 있다. 다음에는 대상 외형·동작을 유지하면서 비대상 원본 문맥을 생성 중 보존하는 제한된 비교를 설계한다. 현재 결과만으로 구현 결함과 모델 한계를 완전히 구분하거나 원인을 확정하지 않으며, 이번에는 합성이나 새 조건 개입을 실행하지 않았다. 추가 모델·학습·seed·긴 영상 실험은 자동 시작하지 않는다.

영상 시도는1회이며 animal/human 영상은 앵커 부적합으로 NOT_RUN이다. 실제 연속 시청은 없고 temporal=UNVERIFIED다. [단계/계보](STAGES.md), [비용](COSTS.md), [재현](REPRODUCE.md), [한국어 해설](../../lessons/B-031-source-aligned-edit-anchor.md).

## 연구 질문과 선택

다음 생성 실험의 후보 경로는 **공식 SCAIL-2 `wan-scail2`의 end-to-end RGB driving + 대응 색상 마스크** 하나로 좁힌다. 수동 동물 관절은 원본 움직임을 검토하고 결과를 평가하는 보조 표현으로 둔다. 임의의 동물 skeleton PNG를 VACE에 넣는 것을 학습된 조건 지원으로 간주하지 않는다.

## 실제 관측·실행 결과

원본 RGB17장과 기존 Canny17장의 파일 SHA 및 decoded RGB 해시를 기존 보존 기록과 대조했다. 전체 17장을 annotation 담당 에이전트가 개별 열람했고, 총괄은 원본 f0/8/16, 해당 3× ID overlay, f0/4/8/12/16 삼단 비교, 전체17 overlay 시트와 궤적을 독립 확인했다. 이는 사람 전문가 ground truth나 블라인드 annotation 일치도 평가가 아니다.

|---|---:|---|
|주석 프레임|17/17|단일 개체·0.708333초의 작은 동작만 포함|
|visible 표면점|119 = 7×17|코·양눈·네 발 끝 부근. 손목/발목 관절 중심이 아님|

머리와 발을 정리했으나 **완전한 skeleton이나 몸통 관절 궤적을 확보한 것은 아니다**. 몸통은 RGB/윤곽에서 보이지만 내부 중심을 눈대중으로 관측 정답으로 채우지 않았다. 수동 점 허용 오차는 눈/코2px, 발4px이며 통계적 신뢰구간이 아니다. 관측점을 연결한 선은 경로 표시일 뿐 중간 점의 보간 정답을 추가하지 않는다.

f0→f16의 이미지 좌표 차이는 코(+3,−6)px, 왼 뒷발(−1,+15)px, 오른 뒷발(−8,+13)px다. endpoint 차이의 성분별 최악 허용 오차는 코±4px, 발±8px다. 인접 프레임 미분은 이 오차가 24배 증폭되어 코±96px/s, 발±192px/s 범위이므로 미세한 frame-to-frame 속도·발 타이밍의 정확한 ground truth를 얻었다고 주장하지 않는다. 카메라와 신체 움직임의 분해도 하지 않았다.

Canny에서는 신체 외곽과 얼굴 내부 선이 남지만 발 주변의 바닥/반사 선도 이어진다. 동일 선분이 어느 관절인지는 주어지지 않는다. 반대로 7점 표현은 ID/불확실성이 명료하지만 몸통 부피·관절 연결·털·가림 표면을 크게 잃는다. 이것이 keypoint-only 생성 경로를 바로 채택하지 않은 실제 근거다.

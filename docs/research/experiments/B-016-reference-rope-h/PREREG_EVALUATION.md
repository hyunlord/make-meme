결과 관측 전 고정. source f7..23의 local0/12/14/16 사건과 전체17프레임을 사용한다. SOURCE / 실제 Lab / 기존 CFG_MOV_H0 / 신규 CFG_MOV_H120을 동일 canvas와 24fps로 비교한다. 17장은0.708333초이며 반복 경계는 내부 동작이 아니다.

사후 warp·정렬·보간·좋은 프레임 선별·각도/좌표 정답 추정은 하지 않는다. 정밀 접촉·가려진 부위·개체 판정은 근거 부족 시 UNCERTAIN이다. 직립만 얻고 identity를 잃거나 얼굴만 보존하고 동작을 잃으면 목표 성공이 아니다. 단일 seed pilot이며 유의성·일반화·상용 품질을 주장하지 않는다.

CPU 검사는 실제 fixed Q/K의 pre-softmax 성질에 한정한다. 허용치는 실행 전 코드에서 고정하며, full softmax와 후속 hidden state의 불변성을 요구하지 않는다. 실제 attention map이나 추가 forward는 만들지 않는다.

pilot 이후 offset sweep·추가 seed·ALG 결합·학습 없이 종료한다. 효과가 없으면 scalar 재탐색 대신 데이터/조건 분리/학습 개입 중 검증 가능한 가설 하나만 제안한다.

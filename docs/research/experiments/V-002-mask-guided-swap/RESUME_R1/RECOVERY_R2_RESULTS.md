# V-002 복구 개정 2 진행 결과

M1 원본 영상은 Mac 전송 후 SHA256 일치를 확인했다. 기존 73프레임 출력(976.877초)을 재사용했고, 출력 SAM은 45.114초에 정상 완료했다. CPU 측정과 9시점 진단 시트를 완료했다. 실제 개 2마리 검출73/73, Lab/IG 평균 실루엣 IoU0.558980, 중심 궤적 거리1.98437%/0.703166%(화면 가로), 반대 최근접 대응 proxy0, Lab/IG 높이비1.50331, 마스크 밖 원본 RGB MAE0.969674, 배경 연속 변화/원본 비율1.85150이다. 이 값들은 사용자 품질 판정을 대신하지 않는다. 새 M1 영상 생성은 하지 않았다.

M2의 이전 시도는 재부팅 뒤 worker와 완료 출력이 없으며 마지막22step/45call이다. 미완료 기록을 보존하고 사용자 승인 1회 재시작을 준비한다. M3는 아직 미실행이다. 14B는 자동 선택하지 않으며 이번 복구에서 14B와 LTX canny를 실행하지 않는다.

실루엣 IoU는 사용자의 E1 동작 불일치 판정과 부합하지 않아 단독 동작 비교·자동 선택 지표로 신뢰도가 낮다. 설명용 값만 유지한다. 모든 새 출력의 품질은 HUMAN_REVIEW_PENDING, 연속 지각 검수는 UNVERIFIED다. 이전 RESULTS/RUNS는 관측 상실 시점의 역사 기록이며 현재 복구 상태는 이 문서와 RECOVERY_R2_RUNS.json을 기준으로 한다.

# V-002 r1 부분 결과 — Spark 관측 상실

**새 영상 M1 한 개의 생성은 확인했지만 아직 Mac에서 볼 수 없다.** M1은 73프레임을 976.877초(약 16분 17초)에 생성했고 원 MP4·PNG는 Spark에 보존됐다. 원 MP4의 Mac 복사·전달 무결성은 확인되지 않았다. M2는 실행 도중 Spark 연결이 끊겨 UNKNOWN이며, M3·14B·LTX canny는 NOT_RUN이다. 이번 검토 묶음에서 재생 가능한 것은 원본과 기존 V-001 E1-s1 영상이며, 두 기준선의 실제 측정·진단 시트를 함께 제공한다.

연결 재확인에서도 SSH timeout과 peer offline이 계속되어 실행을 기술적으로 완료하지 못한 부분 기록이다. 품질은 **HUMAN_REVIEW_PENDING**, 연속 지각 검수는 **temporal=UNVERIFIED**다. 첫 실행 `9f78153`의 `BLOCKED_EXTERNAL_GPU`와 영상 0/5 기록은 변경하지 않았다.

## 실제 실행과 비용

| 단계 | 확인 상태 | 실제 비용·범위 |
|---|---|---|
| V-001 E1-s1 / E1-s2 SAM·CPU 측정 | 완료 | 각각 73프레임, 상세 자동 측정과 9시점 시트 |
| M1 | GENERATED, 출력 SAM NOT_RUN | 832×480·73프레임·24fps, 976.877초, 50 scheduler step / 100 model_fn call |
| M2 | UNKNOWN | 마지막 확인 21/50 scheduler step / 44 model_fn call; 완료 시간·출력 미확인 |
| M3 | NOT_RUN | 호스트 접근 불가 |
| VACE 14B | NOT_RUN | 선택·BF16 변환·1 step 측정·생성 모두 미실행 |
| LTX canny | NOT_RUN | 호스트 접근 불가 |

M1 peak RSS는 13114093568 bytes(약 12.21GiB), CUDA peak allocated는 20036397568 bytes(약 18.66GiB), reserved는 21728591872 bytes(약 20.24GiB)다. 가드 정상 완료를 확인했으며 학습·후합성·출력 endpoint 덮어쓰기는 없다. M1 외형·동작·반사·마스크 밖 보존은 출력 SAM과 사용자 재생 검토가 없으므로 아직 판단하지 않는다.

1280×720 원본 좌표로 환산했고 반사를 실제 개체 수에서 제외했다. 아래는 기존 V-001 결과의 참고 수치이며 V-002 새 출력의 성능 수치가 아니다.

원본 Lab/IG 높이비 중앙값은 1.41850, 앵커는 1.19655다. 기준선의 마스크 밖 MAE는 M1 평가 ROI를 공통 적용한 설명값이며 VACE 마스크 편집 성공을 뜻하지 않는다. SAM 기하 대응과 중심 거리로 춤의 자세·타이밍·정체성을 모두 판정할 수 없다. 사용자가 이미 내린 “개가 움직이지만 원본과 전혀 다른 동작을 한다”는 V-001 판정은 그대로 유지한다. 뒤바뀜 proxy 0도 외형 정체성 보존의 증명이 아니다.

전체 프레임 측정은 [seed 1](metrics/baseline-e1-20261103.json), [seed 2](metrics/baseline-e1-20261104.json), 요약은 [METRICS.json](METRICS.json)에 있다. 새 출력의 미측정 값은 null이며 0점이나 PASS로 채우지 않았다. 기준선 두 영상은 14B 선택 후보가 아니다.

## 관측 상실과 원인 판단의 한계

2026-11-04T19:02Z에 Spark SSH timeout과 Tailscale offline을 확인했다. M2 마지막 관측 가드는 CLEAR였고 관측된 MemAvailable 최저값은 95239196672 bytes(약 88.70GiB), NVRM 이벤트는 없었다. 그 이후 상태를 읽을 수 없어 **OOM·재부팅·worker 종료·정상 진행 중 어느 것도 확인하지 못했다.** 이번 연결 상실을 `ENGINE_STOPPED_NVRM`이나 메모리 실패로 단정하지 않는다. 자체 worker 종료도 미확인이다.

중복 생성·품질 재시도를 시작하지 않는다. 14B 정적 메모리 검토의 보수적 동시 cache 잔류 추정 약 108.415GiB는 실측 peak가 아니며, 변환이나 적재가 일어났다는 뜻도 아니다. 이번에는 후보 선택 자체가 아직 이뤄지지 않았다.

## 실행 계약과 남은 검토

입력 hash 1183개가 일치해 기존 입력을 재사용했다. cache helper는 실제 APPLIED였고 FLS 전용 구조의 slot keeper는 사용하지 않았다. E2 전용 112GiB 시작 조건의 잘못된 상속은 과거 거절을 보존한 별도 r1 guard 사본에서 사용자 r1 계약에 맞게 수정했다. OOM·NVRM·MemAvailable·PSI 런타임 보호는 유지했다. 상세는 [RUNTIME_NOTES.md](RUNTIME_NOTES.md)와 [REPRODUCE.md](REPRODUCE.md)에 있다.

원본 RGB가 마스크 밖 입력 조건으로 남는 것과 생성 출력이 원본 픽셀을 보존하는 것은 다르다. 새 출력의 실루엣·외형·반사·배경과 M3 전환부는 아직 평가하지 못했다. 사용자 검토에는 우선 기존 E1 영상과 실제 기준선 시트를 사용하며, M1이 전달된 것으로 표시하지 않는다. M1–M3 완료 중간 전달은 수행하지 못했다. 대신 Mac에 있는 기존 원본·E1-s1 영상과 이번 기준선 측정·중단 기록만 담은 부분 검토 ZIP을 전달한다. 새 M1 영상과 Spark 간 전송 검증은 UNVERIFIED이며, 패키지 검증은 DELIVERY.json에 별도로 기록한다. 후속 생성·학습·V-003는 예약하지 않는다.

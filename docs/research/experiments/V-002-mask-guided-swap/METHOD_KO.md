# V-002 방법 해설

## 동작 정보가 들어오는 경로

V-001 E1은 첫 프레임 앵커와 축소된 depth 조건으로 전체 영상을 생성했다. 사용자는 원본과 다른 동작이라고 판정했다. V-002는 매 프레임 원본 RGB와 개·반사 영역의 마스크를 제공한다. 움직이는 경계가 위치·실루엣·타이밍 신호를 직접 담지만, 생성된 개의 내부 자세나 픽셀 보존까지 보장하지는 않는다. 팽창은 원래 실루엣 밖으로 Lab을 키울 공간을 주는 동시에 경계 신호를 느슨하게 만든다. 이 값은 결과를 보기 전에 고정했다.

## VACE 조건의 역할

255 마스크는 생성 영역,0은 보존 조건 영역이다. 실제 경로는 입력을 정규화한 뒤 inactive=RGB×(1-mask),reactive=RGB×mask를 각각 VAE로 encode한다. M1의127은 생성 영역의 원래 개 외형을 지우는 중립 회색이다. M2는 그 영역에 기존 depth를 넣어 자세 정보를 추가한다. 참조 Lab/IG 이미지는 앵커에서 실제 개체만 잘라 흰 배경에 배치하고 별도 latent prefix로 전달한다. 참조 두 장의 순서나 prompt만으로 개체 대응이 완벽해진다고 가정하지 않는다.

M3은 입력 frame0 RGB를 앵커로,mask를0으로 만든다. 공식 코드와 기존runner의 nearest-exact 시간 압축에서73→19 mask의 첫 표본은 frame1이라 frame0의0이 그대로 남지 않는다. 따라서 M3은 입력 앵커 조건 실험이며 출력 첫 프레임을 덮어쓰거나 hard clamp하는 실험은 아니다. 마스크 밖 원본도 조건으로 사용되며 모델은 전체 프레임을 decode한다. 배경 pixel exact를 주장하려면 측정 증거가 필요하고 이번에는 후합성을 하지 않는다.

## 시간 압축과 빠른 동작

LTX의8배 시간 압축은73프레임을10 latent시점으로, Wan의4배는19시점으로 줄인다. Wan이 시간 방향에서 더 촘촘한 표현을 쓰지만 이것만으로 발차기 유지가 보장되지는 않는다. 조건 종류·공간 해상도·모델·샘플러가 함께 다르므로 결과 차이를 시간 압축 한 요인의 인과 효과로 해석하지 않는다. 실루엣 IoU·궤적·반사·배경 수치는 참고값이며 최종 밈 사용 가능성은 사용자 재생 검토로 결정한다.

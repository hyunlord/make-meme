B-032의 저비용 기준선과 과거 실패는 보존한다. 다음 검토 가설은 다른 공개 사례에서 같은 고정 제약의 국소 이득과 target 회귀 여부를 확인하는 것 하나이며 자동 실행하지 않는다. [RESULTS](experiments/B-033-clean-prediction-constraint/RESULTS.md).

## 2026-10-26 통합 의뢰의 현재 상태

공개 개발 패널을 유지한 채 B-028의 객체 중심 참조 정규화를 먼저 실행하고, 실제 남은 실패를 본 뒤 생성 메커니즘 개입 하나와 음성 대조를 선택한다. [전체 의뢰서](work_orders/20261026-B028-to-method-research.md)가 이번 상한과 분기를 정의한다. B-028은6출력 완료했으며 외형 일부 개선과 차량 동작/사람 형태 회귀를 확인했다. 공통 기준선은 B-027로 고정하고 [B-029](experiments/B-029-spatial-image-conditioning/PLAN.md)의 이미지 cross-attention 위치 재가중과 공간 음성 대조를 사전 고정했다. B-029는 METHOD6/CONTROL2의 실제40step80forward·17프레임을 모두 확보했다. 동물 교체 실패·사람 참조별 형태 차이·차량 장면 회귀와 CONTROL의 비일관적 결과로 고정 설정을 채택하지 않는다. [결과](experiments/B-029-spatial-image-conditioning/RESULTS.md). 기술 실행과 실제 결합 품질을 구분하고 다음 가설은 별도 승인 전 실행하지 않는다. 개인 사진 확보·학습량 증대·새 모델 설치를 진행 조건으로 삼지 않는다. 아래 기존 종료 관측과 제안은 당시 기록이며 새 방법의 성공 근거가 아니다.

## 2026-10-26 최신 실행 방향 — 공개 다중 사례의 객체 편집

최종 목표는 특정 반려견 전용 모델이 아니라 다양한 대상의 참조 기반 원본 보존 영상 편집이다. 개인 자료는 회귀 사례로 보존하며 전체 연구의 실행 선행조건으로 삼지 않는다. B-026은 OPTIONAL_REFERENCE_DIAGNOSTIC / REFERENCE_PENDING으로 유지하고 새 개인 촬영을 요구하지 않는다.

[B-027](experiments/B-027-public-reference-robustness/PLAN.md)은 공개 DAVIS 자료에서 최대3개 source/target 과제와 같은 target의 두 참조를 고정하는 탐색적 개발 패널이다. SCAIL replacement와 비객체 RGB128을 유지하고 최대6회 실제 출력의 외형·동작·장면·형상·비용을 분리한다. mask-given 평가이며 자동 추적·일반화·논문 benchmark를 입증하지 않는다. 과거 B-023~025의 개선과 실패는 보존하고 다음 방법은 이번 결과를 보고 하나만 선택한다.

## 2026-10-24 최신 방향 — 원본 보존 객체 편집

사용자 목표는 **원본 영상 + 객체별 참조 이미지 + 자연어 편집 지시로, 원본의 장면·시간축·지정 동작을 유지하면서 참조 개체를 치환/합성하는 로컬 시스템**이다. 단일 DGX Spark에서 높은 joint quality와 실측 비용 효율을 얻는 연구를 우선한다. generic T2V, reference 장면 animation, 단순 기능 연결과 구분한다.

상위 계획: [B 연구 v2](RESEARCH_V2_SOURCE_PRESERVING_EDITING.md). 결정 이력: [과제 재정의와 B-023](decisions/20261024-task-redefinition-and-B-023.md). 다음 task-aligned baseline: [B-023 공식 replacement](experiments/B-023-task-aligned-replacement/PLAN.md), 현재 B-023 실행 완료 / 기술 PASS·원본 보존 과제 FAIL. [결과](experiments/B-023-task-aligned-replacement/RESULTS.md).

아래 초기 전략 중 VACE 중심 문장은 당시 기록이다. 현재 확보한 실행 기반은 SCAIL-2와 단계 분리·조건/latent 보존 경로이며, 첫 새 실험은 학습이나 RGBA 모델 신설 대신 정식 replacement 입력·마스크·caption 계약을 검증한다. subject-only 출력·mask만으로 계산 절감을 보장하지 않는다. 국소 생성/재합성/ROI 효율화는 측정할 설계 후보다.

B-022는 실제 완료됐고 품질 개선은 입증되지 않았다. B-021 FAIL과 B-022 기술 PASS/시각 FAIL을 보존하며 같은 학습량 확대를 종료한다. B-023은 같은 실제 Lab 자연동작에서 정식 replacement 계약의 적합성을 한 번 검사한다. EditSpec parser·새 MCP·ROI 합성·복원·효율화·다중 객체는 이번에 구현하지 않는다. 관측 결과로 다음 병목 하나를 선택하며 자동 후속 실행은 하지 않는다.

## 1. 장기 목표

실제 반려동물 사진과 원본 동영상으로부터 개체 외형·체형·안무·시간적 일관성이 유지되는 영상을 만드는 방법을 연구한다. 높은 품질의 실제 영상은 중요한 응용 목표지만, 교육 실습·연구 기여·제품 완성도를 서로 혼동하지 않는다.

사용자가 수식, 수학, 텐서 연산, 모델 코드와 실험 결과를 이해하고 다음 가설을 설계할 수 있게 하는 것이 핵심 목표다. 모델 실행을 대신한 뒤 결과만 반환하는 작업으로 축소하지 않는다.

## 2. 독립적인 두 트랙

### A — native imagegen 전용 MCP

새로운 시각 내용을 만드는 생성 엔진은 native imagegen만 사용한다. 일반 코드의 정렬·전파·합성·인코딩은 허용하지만 로컬 이미지/영상 생성 모델이나 학습 기반 복원·보간 모델을 fallback으로 넣지 않는다.

현재 상태는 동결·보존이다. 기존 기록을 삭제하거나 실패 이력을 성공으로 수정하지 않는다.

### B — 로컬 모델 기반 연구·학습

실제 사진·원본 동영상과 로컬 생성 모델에서 출발한다. native imagegen 및 외부 생성 API를 호출하지 않는다. A의 생성물을 B의 참조·학습·선별 입력으로 사용하지 않는다.

작은 모델과 작은 실험으로 원리를 배우고, 같은 장비에서 실측하며 확장한다. 추론 가능, 역전파 가능, 반복 연구에 실용적이라는 세 판단을 구분한다.

## 3. 초기 연구 전략 — 당시 기록

- 실제 학습 배선과 작은 기준선을 확보한다.
- 반복되는 실패를 하나의 검증 가능한 질문으로 좁힌다.
- 조건을 고정한 비교 실험으로 원인을 구분한다.
- 그 뒤 필요한 데이터·LoRA·adapter 또는 조건 주입 개입 하나를 검토한다.
- 더 큰 모델·서비스·논문으로의 확장은 재현 가능한 증거가 쌓인 뒤 결정한다.

초기 중심 모델은 Wan2.1-VACE-1.3B였다. 모델 이름의 1.3B를 텍스트 인코더·VAE·조건 모듈까지 포함한 전체 파이프라인 파라미터 수로 해석하지 않는다. 새 모델 설치·교체는 최신 실험 계획과 명시된 범위에 따른다.

## 4. 원칙

1. 입력·조건·target·loss를 먼저 정의한다. 존재하지 않는 반려동물 정답 동영상을 가정하지 않는다.
2. 동일 장면 overfit, 개체 학습, 동작 학습, 미관측 영상 일반화를 구분한다.
3. 모델 출력의 사실, 원인에 대한 추론, 미검증 가설을 분리한다.
4. 코드 테스트 통과와 학습 업데이트는 영상 품질 성공을 뜻하지 않는다.
5. 실패·생략·중단도 결과다. 좋은 sample만 선별해 전체 성공으로 보고하지 않는다.
6. 수식은 실제 고정 코드 버전과 연결한다. 설명용 시간 방향과 실제 scheduler의 부호를 확인한다.
7. 연구 기록은 작업 전·주요 단계 후·작업 종료 시 갱신한다.

## 5. 성공을 구분하는 기준

| 종류 | 필요한 증거 |
|---|---|
| 학습 실습 | 실제 실행, gradient/업데이트/샘플링 확인, 원리 설명 |
| 연구 실험 | 고정 조건 비교, 한계와 반례, 재현 가능한 데이터·설정 |
| 일반화 | 미사용 scene/identity/motion에서의 평가 |
| 서비스 후보 | 제한된 목표 범위의 반복 성공률과 실패 포함 비용 |
| 논문 후보 | 선행 연구 대비 명확한 새 가설·방법, 여러 조건의 검증과 ablation |

두 seed의 탐색 실험이나 한 장면 복원을 논문 성능·Kling 대체의 증거로 사용하지 않는다.

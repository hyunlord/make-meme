# 연구 방향과 목표

작성: 2026-10-22 · 실행 환경: 사용자가 보유한 DGX Spark를 우선한다.

## 2026-10-24 최신 방향 — 원본 보존 객체 편집

사용자 목표는 **원본 영상 + 객체별 참조 이미지 + 자연어 편집 지시로, 원본의 장면·시간축·지정 동작을 유지하면서 참조 개체를 치환/합성하는 로컬 시스템**이다. 단일 DGX Spark에서 높은 joint quality와 실측 비용 효율을 얻는 연구를 우선한다. generic T2V, reference 장면 animation, 단순 기능 연결과 구분한다.

상위 계획: [B 연구 v2](RESEARCH_V2_SOURCE_PRESERVING_EDITING.md). 결정 이력: [과제 재정의와 B-023](decisions/20261024-task-redefinition-and-B-023.md). 다음 task-aligned baseline: [B-023 공식 replacement](experiments/B-023-task-aligned-replacement/PLAN.md), 현재 PLANNED / NOT_RUN.

아래 초기 전략 중 VACE 중심 문장은 당시 기록이다. 현재 확보한 실행 기반은 SCAIL-2와 단계 분리·조건/latent 보존 경로이며, 첫 새 실험은 학습이나 RGBA 모델 신설 대신 정식 replacement 입력·마스크·caption 계약을 검증한다. subject-only 출력·mask만으로 계산 절감을 보장하지 않는다. 국소 생성/재합성/ROI 효율화는 측정할 설계 후보다.

B-022가 이미 실행 중이면 종료시키지 않고 기존 범위·이력을 보존한다. 미착수라면 새 주력은 B-023이며 B-022는 후순위 학습량 진단이다. 이전 실험의 실패나 완료를 소급 수정하지 않는다. 현재 문서 변경은 GPU 실행·학습·모델 다운로드가 아니다.

## 1. 장기 목표

실제 반려동물 사진과 원본 동영상으로부터 개체 외형·체형·안무·시간적 일관성이 유지되는 영상을 만드는 방법을 연구한다. 높은 품질의 실제 영상은 중요한 응용 목표지만, 교육 실습·연구 기여·제품 완성도를 서로 혼동하지 않는다.

사용자가 수식, 수학, 텐서 연산, 모델 코드와 실험 결과를 이해하고 다음 가설을 설계할 수 있게 하는 것이 핵심 목표다. 모델 실행을 대신한 뒤 결과만 반환하는 작업으로 축소하지 않는다.

## 2. 독립적인 두 트랙

### A — native imagegen 전용 MCP

새로운 시각 내용을 만드는 생성 엔진은 native imagegen만 사용한다. 일반 코드의 정렬·전파·합성·인코딩은 허용하지만 로컬 이미지/영상 생성 모델이나 학습 기반 복원·보간 모델을 fallback으로 넣지 않는다.

현재 상태는 동결·보존이다. 기존 기록을 삭제하거나 실패 이력을 성공으로 수정하지 않는다.

### B — 로컬 모델 기반 연구·학습

실제 사진·원본 동영상과 로컬 생성 모델에서 출발한다. native imagegen 및 외부 생성 API를 호출하지 않는다. A의 생성물을 B의 참조·학습·선별 입력으로 사용하지 않는다.

작은 모델과 작은 실험으로 원리를 배우고, 같은 장비에서 실측하며 확장한다. 추론 가능, 역전파 가능, 반복 연구에 실용적이라는 세 판단을 구분한다.

## 3. 초기 연구 전략 — 당시 기록

- 실제 학습 배선과 작은 기준선을 확보한다.
- 반복되는 실패를 하나의 검증 가능한 질문으로 좁힌다.
- 조건을 고정한 비교 실험으로 원인을 구분한다.
- 그 뒤 필요한 데이터·LoRA·adapter 또는 조건 주입 개입 하나를 검토한다.
- 더 큰 모델·서비스·논문으로의 확장은 재현 가능한 증거가 쌓인 뒤 결정한다.

초기 중심 모델은 Wan2.1-VACE-1.3B였다. 모델 이름의 1.3B를 텍스트 인코더·VAE·조건 모듈까지 포함한 전체 파이프라인 파라미터 수로 해석하지 않는다. 새 모델 설치·교체는 최신 실험 계획과 명시된 범위에 따른다.

## 4. 원칙

1. 입력·조건·target·loss를 먼저 정의한다. 존재하지 않는 반려동물 정답 동영상을 가정하지 않는다.
2. 동일 장면 overfit, 개체 학습, 동작 학습, 미관측 영상 일반화를 구분한다.
3. 모델 출력의 사실, 원인에 대한 추론, 미검증 가설을 분리한다.
4. 코드 테스트 통과와 학습 업데이트는 영상 품질 성공을 뜻하지 않는다.
5. 실패·생략·중단도 결과다. 좋은 sample만 선별해 전체 성공으로 보고하지 않는다.
6. 수식은 실제 고정 코드 버전과 연결한다. 설명용 시간 방향과 실제 scheduler의 부호를 확인한다.
7. 연구 기록은 작업 전·주요 단계 후·작업 종료 시 갱신한다.

## 5. 성공을 구분하는 기준

| 종류 | 필요한 증거 |
|---|---|
| 학습 실습 | 실제 실행, gradient/업데이트/샘플링 확인, 원리 설명 |
| 연구 실험 | 고정 조건 비교, 한계와 반례, 재현 가능한 데이터·설정 |
| 일반화 | 미사용 scene/identity/motion에서의 평가 |
| 서비스 후보 | 제한된 목표 범위의 반복 성공률과 실패 포함 비용 |
| 논문 후보 | 선행 연구 대비 명확한 새 가설·방법, 여러 조건의 검증과 ablation |

두 seed의 탐색 실험이나 한 장면 복원을 논문 성능·Kling 대체의 증거로 사용하지 않는다.

## 4. 변형

### R1 — 다듬기 패스 (S2 출력을 약하게 다시 생성)

- 입력: **V-004 S2-s1 RAW** 73프레임.
- 방법: 입력 영상을 VAE로 인코딩하고 노이즈 수준 σ까지만 노이즈를 더한 뒤, 그 σ부터 끝까지 S2와 같은 조건(앵커 + 확대 canny + 프롬프트)으로 denoise한다. 흔히 SDEdit 또는 video-to-video strength라고 부르는 방식이다.
  - 공식 파이프라인에 입력 영상과 강도를 받는 경로가 있으면 그것을 쓴다.
  - 없으면 파이프라인 코드에서 **초기 latent를 "입력 latent + 노이즈"로 바꾸고 schedule의 해당 σ 단계부터 시작하는 최소 수정**을 허용한다. 수정 diff를 `RUNTIME_REFINE.md`에 남긴다.
  - two-stage 경로에서는 1단계와 2단계 모두 같은 방식으로 시작 σ를 맞춘다. 단계별 실제 시작 σ와 남은 step 수를 기록한다.
- 강도 두 가지: **σ = 0.35(R1-a), 0.55(R1-b).** schedule에 정확한 값이 없으면 가장 가까운 단계를 쓰고 실제 값을 기록한다.
- seed: `20261103`.
- **국소 합성(CPU 파생본)**: 다듬은 영상은 RAW 전체를 그대로 보존한다. 그와 별도로 "다리 영역만 교체한" 파생본을 하나 더 만든다.
  - 영역: 프레임 14~34에서 출력 Lab SAM 마스크의 bbox 아래쪽 45%를 12px 팽창하고 8px로 경계를 부드럽게 한 범위.
  - 시간 경계: 14~17과 31~34에서 0→1, 1→0으로 선형 전환한다.
  - 이 영역은 다듬은 픽셀로, 나머지는 S2-s1 RAW로 채운다.

### R2 — 전체 단계 모델 (distilled 아님)

  2. 라이선스가 distilled와 같은지

## 7. ROADMAP 반영과 학습 데이터 기록 규칙

### 7.1 ROADMAP
저장소 `ROADMAP.md`에 다음 3단계 로드맵을 반영한다. HISTORY에 V-004 종료와 V-005 시작을 한 줄씩 남긴다.

   - 넘어가는 조건: 사용자 Kling 대비 판정 "비슷함" 이상.
2. **어댑터 학습.** 공개 영상 모델에 IC-LoRA·어댑터를 학습한다. 입력은 원본 영상 + SAM 마스크·트랙 + 참조 사진이다. 개체별 참조 어텐션을 검토한다.
   - 넘어가는 조건: 클립 수십 개에서 1단계와 품질이 동등 이상.
3. **압축·경량화.** 양자화, 단계 축소, 어텐션 희소화·캐시를 적용하고 품질 대 속도·메모리 곡선을 만든다. 논문 여부는 이때 판단한다.

원칙: 품질 먼저, 단계마다 그 자체로 쓸모 있는 결과물, 장면 특화 값은 설정 파일에만 둔다.

### 7.2 학습 데이터 기록 (V-005부터 계속 적용)

- 구조 조건(canny/확대 canny) 경로·hash

## 8. 예산과 순서

| 단계 | 승인량 |
|---|---:|
| imagegen | 4장 신규 + 보정 최대 4회 = 최대 8회 |
| SAM | 신규 앵커 최대 8장, 출력 6개(+ R1 국소 합성 확인) |
| 생성·다듬기 | 최대 6회(R1 2, R2 2, R3 2) |
| 체크포인트 다운로드 | R2용 1세트 |
| 품질 재시도 | 0회 |
| 전체 상한 | 6시간(외부 GPU 대기와 다운로드 제외). 마지막 30분은 기록·전달 |

순서: 인수 → 사전 commit(설정·강도·위치·지표 정의) → R2 지원 여부 확인과 다운로드 시작(백그라운드) → R1-a → R1-b → 국소 합성 → 신규 앵커 4장 → R3-s1 → R2-s1 → **중간 전달**(R1 두 개, R3-s1, R2-s1) → R3-s2 → R2-s2 → 측정 → 뷰어 → 데이터 기록 → ROADMAP → 전달.

R1을 먼저 하는 이유: 가장 싸고, 해결 가능성이 가장 높다.
